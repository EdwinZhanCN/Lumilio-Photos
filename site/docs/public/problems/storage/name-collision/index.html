Lumilio API Problems

Destination volume cannot tell indexed names apart

Type
https://lumilio.org/problems/storage/name-collision
Normal HTTP status
409
Definition
Under the case or normalization rule of the destination volume, indexed paths of the Repository would share one name, so the reconnect was refused before any row or byte changed.
Recovery
Rename one of each named pair on the original volume, or reconnect to a volume that distinguishes them; the index was not changed.

Extension members

NameSchemaMeaning
collision_countintegerHow many live entries would share another entry's name on the destination.
collisionsarray[object]At most ten of the colliding pairs, each with first and second repository-relative paths.

Runtime clients identify this condition by type; they do not dereference this page automatically.
