Lumilio API Problems

Volume name rules unqualified

Type
https://lumilio.org/problems/storage/volume-unqualified
Normal HTTP status
409
Definition
The name comparison rule of the volume holding the target folder could not be measured, or directories of the tree follow different rules, so the Repository was not registered or reconnected there.
Recovery
Check that the folder is writable and that no per-directory case-folding flag differs inside the tree, then try again; a volume Lumilio cannot qualify is not used.

Extension members

This Problem type defines no extension members.

Runtime clients identify this condition by type; they do not dereference this page automatically.
