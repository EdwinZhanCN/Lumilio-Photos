Lumilio API Problems

Repository action unavailable

Type
https://lumilio.org/problems/storage/action-unavailable
Normal HTTP status
409
Definition
The role-aware storage policy withholds this Repository action on the current facts, so the command was not run.
Recovery
Read the blockers and take one of the listed alternatives; the same action is not retried automatically.

Extension members

NameSchemaMeaning
actionstringThe withheld action: verify, rename, detach, or reconnect.
blockersarray[string]Stable codes naming why the action is withheld.
alternativesarray[string]Stable codes naming legal entries to take instead.

Runtime clients identify this condition by type; they do not dereference this page automatically.
