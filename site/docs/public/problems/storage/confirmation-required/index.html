Lumilio API Problems

Storage confirmation required

Type
https://lumilio.org/problems/storage/confirmation-required
Normal HTTP status
409
Definition
The storage target carries placement risks that the administrator has not acknowledged for this command.
Recovery
Review the listed risks, then retry the same command with the assessment token and every risk code acknowledged.
Recovery entry
actor admin, phase any, kind retry

Extension members

NameSchemaMeaning
risksarray[string]Stable risk codes the command requires acknowledged.
assessment_tokenstringOpaque token binding an acknowledgement to the assessed target facts.

Runtime clients identify this condition by type; they do not dereference this page automatically.
