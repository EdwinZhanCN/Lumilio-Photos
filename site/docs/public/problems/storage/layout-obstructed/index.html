Lumilio API Problems

Repository layout repair obstructed

Type
https://lumilio.org/problems/storage/layout-obstructed
Normal HTTP status
409
Definition
The Repository at the target is missing part of its layout, and a file or a denied directory sits where the missing directory belongs, so the bounded repair was not run.
Recovery
Move the obstructing file out of the Repository folder or fix its permissions, then review the setup target again; nothing in the folder was changed. Choosing a fresh Default Storage Location is the other way out.

Extension members

This Problem type defines no extension members.

Runtime clients identify this condition by type; they do not dereference this page automatically.
