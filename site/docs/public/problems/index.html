Lumilio API Problems

Stable RFC 9457 Problem type documentation for the Lumilio API.

  • https://lumilio.org/problems/agent/operation-failed — The Agent operation could not be completed.
  • https://lumilio.org/problems/asset/missing — The Asset has no present file. Reconnect its Repository or return the file and scan again.
  • https://lumilio.org/problems/asset/offline — All copies of the Asset are in unavailable Repositories.
  • https://lumilio.org/problems/asset/trashed — The Asset is in the Trash. Restore it to open the original.
  • https://lumilio.org/problems/auth/authentication-required — A valid authenticated session is required for this operation.
  • https://lumilio.org/problems/auth/invalid-credentials — The supplied sign-in credentials were not accepted.
  • https://lumilio.org/problems/auth/mfa-invalid — The supplied multi-factor authentication proof was not accepted.
  • https://lumilio.org/problems/auth/passkey-unavailable — Passkey authentication is unavailable for this request.
  • https://lumilio.org/problems/auth/permission-denied — The authenticated user cannot perform this operation.
  • https://lumilio.org/problems/auth/rate-limited — Authentication requests are temporarily rate limited.
  • https://lumilio.org/problems/auth/session-expired — The browser session can no longer be refreshed.
  • https://lumilio.org/problems/auth/untrusted-origin — The browser request origin is not trusted for a session-changing operation.
  • https://lumilio.org/problems/backup/restore-failed — An accepted database restore could not be completed.
  • https://lumilio.org/problems/bootstrap/app-not-initialized — First-run setup must finish before this operation is available.
  • https://lumilio.org/problems/cloud/import-failed — An accepted cloud import could not be completed.
  • https://lumilio.org/problems/lumen/image-semantic-analysis-unavailable — Image Semantic Analysis is not currently available.
  • https://lumilio.org/problems/media/image-embedding-missing — The selected asset does not have an Image Semantic Analysis embedding.
  • https://lumilio.org/problems/media/invalid-request — The requested media operation cannot process the supplied media.
  • https://lumilio.org/problems/repository/conflict — Repository state requires an explicit recovery choice.
  • https://lumilio.org/problems/repository/scan-failed — An accepted Repository scan could not be completed.
  • https://lumilio.org/problems/repository/scan-incomplete — A Repository scan completed with partial results.
  • https://lumilio.org/problems/repository/unavailable — The Repository required by the operation is unavailable.
  • https://lumilio.org/problems/service/unavailable — A required optional service is currently unavailable.
  • https://lumilio.org/problems/storage/action-unavailable — The role-aware storage policy withholds this Repository action on the current facts, so the command was not run.
  • https://lumilio.org/problems/storage/assessment-stale — The facts of the storage target changed since it was assessed, so the supplied acknowledgement no longer applies.
  • https://lumilio.org/problems/storage/busy — Another storage command holds the Repository barrier, so this command did not start.
  • https://lumilio.org/problems/storage/confirmation-required — The storage target carries placement risks that the administrator has not acknowledged for this command.
  • https://lumilio.org/problems/storage/host-action-expired — A native host action expired before Desktop approved it; nothing was changed.
  • https://lumilio.org/problems/storage/host-action-failed — An accepted native host action could not be completed.
  • https://lumilio.org/problems/storage/identity-mismatch — The marker at the path carries a different Repository identity than the registration the command targets.
  • https://lumilio.org/problems/storage/layout-obstructed — The Repository at the target is missing part of its layout, and a file or a denied directory sits where the missing directory belongs, so the bounded repair was not run.
  • https://lumilio.org/problems/storage/materialization-required — The storage target holds cloud placeholders whose content is not available locally.
  • https://lumilio.org/problems/storage/name-collision — Under the case or normalization rule of the destination volume, indexed paths of the Repository would share one name, so the reconnect was refused before any row or byte changed.
  • https://lumilio.org/problems/storage/not-a-mounted-volume — The existing empty target lives in the ephemeral container layer rather than on a mounted host volume.
  • https://lumilio.org/problems/storage/observation-unknown — The filesystem facts of the storage target could not be read, so its support and risks are unknown.
  • https://lumilio.org/problems/storage/original-online — The registered Repository is still present at its original path, so there is nothing to reconnect.
  • https://lumilio.org/problems/storage/ownership-unavailable — Another process owns the Repository tree, so this Server cannot take the exclusive ownership the command needs.
  • https://lumilio.org/problems/storage/permission-denied — The Server was denied access to the storage target.
  • https://lumilio.org/problems/storage/recovery-required — An interrupted storage operation left the journal of this Repository open; conflicting commands are refused until journal recovery completes.
  • https://lumilio.org/problems/storage/unsupported-filesystem — The storage target is on a network or remote filesystem that this release does not support for Storage Locations and Repositories.
  • https://lumilio.org/problems/storage/volume-unqualified — The name comparison rule of the volume holding the target folder could not be measured, or directories of the tree follow different rules, so the Repository was not registered or reconnected there.
  • https://lumilio.org/problems/upload/processing-failed — An accepted upload could not be processed.
