A good order to get familiar with Lumilio Photos:

1. **Import**: start with [Add Media to a Repository](./manage) to understand the difference between upload, scan, cloud import, and background processing;
2. **Browse**: read [Browse, Filter & Batch](./assets) and learn to pick a repository scope before searching, filtering, and batch operations;
3. **Organize**: use [Collections](./collections) and albums to build manual and automatic views;
4. **Clean up**: review candidates in [Duplicates, Likes & Trash](./utilities), then merge or restore after confirming;
5. **Output**: use [Studio](./studio) when you need new files, and share links when others need to view;
6. **Extend**: after the base flow is stable, enable [Lumen Intelligence](./lumen-intelligence) or [Lumilio Agent](./agent) as needed;
7. **Maintain**: administrators use [Account, Users & Preferences](./settings) and the [Server Monitor](./monitor) for security, backups, and background tasks.

“Collections” is an organizing and browsing entry point, not a new storage location. Lumen Intelligence and Lumilio Agent are optional enhancements and never replace original-media backups.
