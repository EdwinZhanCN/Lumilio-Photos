# Collections

## Overview

The Assets gallery and collections show photos and videos by default.
Browse audio in Music; directly opened or shared audio still supports playback.

## Events

Events group photos and videos (including Live Photos) by time and location.
Audio never affects automatic grouping and cannot be added manually in rc.1,
even when a recording has capture metadata. Event counts, covers, gallery,
viewer navigation, and Event shares use the same photo/video members.
Repository Browse Scope filters that set without changing the Event itself.
Rebuilding preserves manual corrections on photo/video members.
