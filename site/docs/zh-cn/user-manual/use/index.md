# 使用流明集

日常使用从“首页”“资源库”“合集”“管理”“工作室”和“设置”等入口展开。管理员会额外看到 Server Monitor；Lumilio Agent 只有在系统设置和模型提供方均可用时才能开始新对话。

## 常见任务

- [浏览资源库](./browse.md)并查看媒体信息；
- 使用[搜索](./search.md)、筛选和语义能力查找内容；
- 通过[上传、扫描或云导入](./add-media.md)添加媒体；
- 使用[相册、堆叠、标签、人物和事件](./organize.md)整理；
- 处理[重复项与回收站](./duplicates-trash.md)；
- 在[工作室](./studio.md)保存非破坏性编辑并导出；
- 创建和撤销[分享链接](./sharing.md)；
- 按能力状态使用[Lumen Intelligence](./lumen-intelligence.md)和[Lumilio Agent](./agent.md)。

多数页面支持资源库范围或当前工作范围。范围影响查询、上传目标或索引操作，但不会移动原件；执行批量操作前应再次确认当前范围和选中数量。
