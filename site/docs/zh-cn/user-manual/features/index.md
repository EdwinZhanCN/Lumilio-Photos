# 使用指南

建议熟悉顺序：

1. **导入**：[把媒体加入资源库](./manage)——上传、扫描、云导入的区别；
2. **浏览**：[浏览、筛选与批量操作](./assets)——先选范围，再搜索筛选；
3. **整理**：[相册与合集](./collections)、[人物、地点与事件](./people)；
4. **清理**：[重复项、喜欢与回收站](./utilities)——审核后合并或恢复；
5. **输出**：[工作室](./studio) 导出新文件，[分享链接](./sharing) 给他人查看；
6. **增强**：按需启用 [Lumen Intelligence](./lumen-intelligence) 或 [Lumilio Agent](./agent)；
7. **维护**：管理员用[设置](./settings)和[状态页](./monitor)处理安全、备份和后台任务。

合集是浏览入口，不是新的存储位置；Lumen Intelligence 和 Lumilio Agent 是可选增强，都不替代原始媒体备份。路径、挂载、扫描或队列问题，见「高级与参考」中的进阶页面。
