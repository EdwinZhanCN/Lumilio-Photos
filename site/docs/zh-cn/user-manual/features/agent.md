# Lumilio Agent

Lumilio Agent 是对话式整理助手：用自然语言描述想做的事，它在**当前账户和已授权资源库范围内**调用整理工具。每个会改变整理关系的操作都要**精确确认**，执行结果以服务器**回执**为准。

## 典型用法

**从选中的照片建立相册**：

1. 在资源库选中一批照片（消息旁会显示本次的选择范围）；
2. 问：「把这些照片建成一个叫“海边假期”的相册」；
3. 检查 Agent 给出的影响范围（目标相册、媒体数量）；
4. 点**确认**——这只是提交，界面会显示 `submitting → committed / rejected / failed / cancelled`；
5. 看到服务器返回**回执**（effect receipt）后，操作才算已应用。

其他真实任务：**批量打标签**（「给这批照片加“2024 旅行”标签」）、**审阅结果**（「列出这些照片里重复的」）、**整理**（「按主题把选中媒体归拢」）。取消、停止或关闭对话**不会提交**被中断的修改。

## 消息旁的显示

每条用户消息旁会显示本次的 **mode（模式）、selection/viewing scope（选择/查看范围）和 mentions（引用）**。**被丢弃的引用不会静默忽略**：无法解析或超出权限的提及会明确标出，可修正后继续。

结果集是当前查询和权限下的**工作快照**：新导入、删除或权限变化后，它可能与稍后打开的浏览页不同。想保留某个结果，把它 **pin 到看板（Board）**——会话记忆是临时的，**pin、看板、媒体变更和回执才是持久事实**。

## 状态：未配置、禁用、不可达

- **未配置**：还没选 LLM 提供方和模型，入口明确提示；
- **禁用**：管理员关闭了「启用 Lumilio Agent」；
- **不可达**：已配置但连接失败、密钥无效或校验未通过。

三种状态都如实显示。**基础媒体库不依赖 Agent**——任何状态下导入、浏览、整理照常工作。

## 配置与隐私

管理员在 **设置 → AI** 配置（详见 [AI 设置](./settings)）：

- 提供方**显式选择**，无默认回退；DeepSeek/Ollama 需填 **Base URL**，远端提供方需 **API Key**；
- **验证连接**只验证未保存草稿，失败不保存；**切换提供方需重新提供 secret**；
- 「启用 Agent」和「验证提供方」是两个动作。

**数据边界取决于提供方**：本地提供方（如 Ollama）的问题和引用元数据留在本机；远端提供方会把问题、引用上下文和工具结果发送给它，是否离开设备取决于其数据保留规则。启用前请查看隐私政策与费用。
