# Lumilio Agent

Lumilio Agent 是 Lumilio Photos 中的对话式整理助手。它与负责媒体 ML 处理的 [Lumen AI](./lumen-ai) 相互独立：Agent 需要配置 LLM 提供方，Lumen AI 则负责语义索引、OCR、人脸等后台处理任务。

## 从哪里打开 Lumilio Agent

你可以从以下入口打开 Lumilio Agent：

- 侧边栏中的 Agent 页面；
- 全局浮动入口；
- 媒体查看器中的提问入口。

不同入口都使用同一套账户权限和资源库范围。未登录、没有资源库访问权或 LLM 配置不可用时，Lumilio Agent 不会绕过这些限制读取媒体。

## 先提问，再检查结果集

Lumilio Agent 可以引用人物、相册、合集、相机、镜头、事件和固定项等上下文。它通常会先生成一个结果集，再让界面以媒体封面、拼图、数量或时间线组件展示结果。

建议按下面的顺序使用：

1. 说明你想找什么，并给出必要的时间、资源库或人物范围；
2. 检查返回数量和结果集中的实际媒体；
3. 需要时在看板中固定结果，继续比较或分享；
4. 只有确认范围正确后，才执行整理操作。

结果集是当前查询和权限下的工作快照，不是永久不变的筛选器。新导入、删除、回收站恢复或权限变化，都可能使它与稍后打开的浏览页不同。

## 会改变整理关系的操作必须确认

创建相册、添加标签、批量喜欢或其他会改变整理关系的操作，会停在**需要确认**状态。确认前至少检查：

- 目标资源库和当前账户；
- 结果集数量是否符合问题本意；
- 操作是添加、移除还是覆盖；
- 是否会影响已有相册成员关系或回收站状态。

取消、停止生成或关闭对话不会自动提交被中断的修改。最终结果请以页面成功提示和资源库中的实际状态为准。

## 配置与隐私

管理员在 **设置 → AI** 中配置 LLM 提供方、模型、可选 Base URL 和 API Key。验证连接前请检查提供方的隐私政策、费用和数据保留规则。Lumilio Agent 的问题、引用的上下文和工具结果是否离开本机，取决于所选提供方和部署方式。

Agent 引用、结果集快照、工具确认和隐私边界见 [Lumilio Agent 进阶](../help/agent-details)。
