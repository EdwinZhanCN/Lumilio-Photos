# 首页与统计

<DocPath :items="['侧边栏', '首页']" />

首页（侧边栏最上方的房屋图标）是一个只读的总览页。它不会创建资源库、移动文件或替代资源库浏览页；首页中的操作最终都会跳转到真正负责该任务的页面。

## 选择首页范围

顶部的**图库范围**可以选择**全部资源库**或某一个资源库。精选媒体、统计数字和地图点都会按这个范围重新请求；切换范围不会改变任何媒体或合集关系。

## 精选媒体

默认的**精选**区域从当前范围中选取一小组代表性媒体，适合快速回顾。点击缩略图会打开资源库查看器，继续使用完整的搜索、筛选和批量操作；首页本身不提供删除、加标签或添加到相册的按钮。

如果精选区域为空，先确认当前范围已有可浏览媒体，再检查媒体是否仍在导入或缩略图任务排队。它不是随机文件浏览器，也不会显示已经标记为删除的媒体。

## 统计

切换到**统计**标签可以查看：

- 焦段分布；
- 相机和镜头排行；
- 按小时或月份的活动分布；
- 按年份查看每日活动热力图。

统计来自已登记的元数据。没有 EXIF 或拍摄时间的媒体可能不会出现在对应图表中；切换资源库范围或热力图年份后，页面会重新加载数据。

## 地图预览

首页的地图卡片只加载一个有限的预览集合，并按 GPS 坐标显示地点点位。点击点位会跳到该媒体的查看器；想使用完整地图、范围筛选或行程视图，请进入[人物、地点与事件](./people)或资源库的地图入口。

没有 GPS 的媒体不会因为打开首页地图而被推断出地点。地图本身也不会修改媒体的位置信息。

::: tip 首页看不到刚导入的媒体怎么办
先检查顶部范围，再到[浏览、筛选与批量操作](./assets)直接搜索。首页精选和统计有短暂缓存，后台导入、元数据读取或地点聚类完成后可能需要刷新页面才会出现新结果。
:::
