# 首页与统计

首页（侧边栏顶部房屋图标）是只读总览页：精选媒体、统计和地图都按顶部选择的**图库范围**展示。

## 精选媒体

默认区域展示当前范围的一小组代表性媒体。点击缩略图进入资源库查看器继续操作；首页本身不提供删除、标签等按钮。

**精选为空时**：先确认范围正确、媒体已导入完成（缩略图任务可能仍在队列，到[状态页](./monitor)确认）。

## 统计

**统计**标签查看焦段分布、相机/镜头排行、按小时/月份的活动分布和按年份的每日热力图。统计来自已登记元数据；没有 EXIF/拍摄时间的媒体不会出现在对应图表中。

## 地图预览

地图卡片按 GPS 显示地点点位，点击点位进入媒体查看器。没有 GPS 的媒体不会被推断出位置。完整地图、范围筛选和行程视图在[人物、地点与事件](./people)。
