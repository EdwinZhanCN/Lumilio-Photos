# 人物、地点与事件

人物、地点和事件由媒体中的人脸、GPS 和拍摄时间自动生成，适合快速发现内容。**修改它们改变的是整理关系和显示信息，不是原始媒体文件。**

| 入口 | 回答的问题 | 依据 |
| --- | --- | --- |
| **人物** | 哪些媒体里是同一个人？ | 人脸检测与聚类 |
| **地点** | 媒体在哪里拍的？ | GPS 与聚类 |
| **事件** | 哪些媒体属于同一段时间？ | 时间、位置与算法 |

> 新导入的媒体没有结果很正常：缩略图、人脸、地点聚类还在后台队列。先到[状态页](./monitor)确认任务完成，再判断是否异常。

## 人物

1. 打开**合集 → 人物**，切换**显示中/全部**（隐藏人物只从默认列表移除）。
2. 点卡片进入详情：上半部分是媒体浏览器，可像资源库一样查看和分享。
3. 点**编辑**：
   - **信息**：重命名（命名后标记为已确认）、隐藏；
   - **人脸**：设封面、批量移动或移除人脸；
   - **合并**：选择其他人物合并进来（合并前检查双方人脸，避免把不同的人合成一个）。

> 移动/移除人脸只改变关联，不修改媒体，也不进回收站。

## 地点

1. 打开**合集 → 地点**，选择范围；
2. 拖动/缩放地图，密集区域显示数字标记，点击逐级放大；
3. 点单个点查看缩略信息，再进入查看器。

地图只显示已有 GPS 的媒体；没有 GPS 的媒体不会被推断出位置。行程卡片是把一段时间+地点的媒体聚合成的回顾视图，不是可编辑的相册。

## 事件

1. 打开**合集 → 事件**，查看自动生成的卡片（名称、时间范围、封面、数量）。
2. 打开事件后可：重命名、设封面、添加/移除媒体、在所选媒体前拆分、移动到其他事件、合并、隐藏、分享。
3. 列表为空或过时时，点标题栏**重新构建**。

> 添加/移除/拆分/合并会写入人工约束；页面提示「等待事件重新构建」说明约束已保存、自动分组尚未完成，重建后重新检查。从事件移除媒体不删除媒体；真删除请回资源库用**移入回收站**。

## 没有结果时按顺序检查

1. [状态页](./monitor)确认相关任务未持续失败；
2. 人物分组不正确：**管理**页顶部**重建人物识别**（跨资源库操作）；
3. 地图缺位置：资源库卡片 **⋯** → **重建位置聚类**；
4. 事件为空/过时：**合集 → 事件 → 重新构建**；
5. 确认图库范围没选错。

::: info 隐私提醒
人物、位置、拍摄时间都可能是敏感信息。创建公开分享前检查范围，并用未登录窗口确认接收者实际看到的内容。
:::
