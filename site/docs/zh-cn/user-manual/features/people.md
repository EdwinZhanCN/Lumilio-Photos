# 人物、地点与事件

<DocPath :items="['侧边栏', '人物、地点与事件']" />

人物、地点和事件不是手动创建的相册。它们由媒体中的人脸、GPS、拍摄时间和其他索引结果生成，适合快速发现内容；后台任务完成前，结果可能为空或不完整。修改人物或事件时，改变的是整理关系和显示信息，不是原始媒体文件。

## 先了解三个入口

| 入口 | 它回答的问题 | 主要依据 |
| --- | --- | --- |
| **人物** | “哪些媒体中出现了同一个人？” | 人脸检测与聚类 |
| **地点** | “媒体在哪里记录？” | GPS 坐标和地点聚类 |
| **事件** | “哪些媒体属于同一段时间和活动？” | 拍摄时间、位置和事件算法 |

三个入口都位于**合集**。人物和地点页面可以在标题栏切换**图库范围**；事件列表按当前账户显示活动事件，详情页中的媒体仍可以使用浏览范围和普通筛选。

::: tip 新导入的媒体还没有结果
上传或扫描完成只代表原始媒体已经登记。缩略图、人脸、GPS 地点聚类和事件分组还可能在后台队列中。先到[状态页](./monitor)确认相关任务是否完成，再判断“没有人物”或“没有事件”是否异常。
:::

## 人物：检查和修正人脸分组

### 浏览人物

1. 打开**合集 → 人物**。
2. 在标题栏选择**显示中**或**全部**。**显示中**不包含被隐藏的人物；**全部**会把隐藏人物也列出。
3. 点击人物卡片进入详情。卡片中的封面、名称和媒体数量来自当前识别结果；尚未命名的人物会显示为“未命名”。

人物详情的上半部分是媒体浏览器，可以像资源库一样打开查看器、筛选或分享选中的媒体。点击**编辑**后，会打开人物编辑窗口。

### 编辑人物

编辑窗口有三个标签页：

- **信息**：修改人物名称。保存名称后，该人物会被标记为已确认；打开**隐藏**只会把它从默认人物网格中移除，不会删除媒体或人脸关联。
- **人脸**：检查 Lumilio 分配给该人物的人脸。可以把某张人脸设为人物封面，也可以进入选择模式，批量移动或移除人脸。这个面板按人物查询，不会因为当前图库范围而隐藏其他资源库的人脸。
- **合并**：选择一个或多个其他人物，将其合并到当前人物。合并前请先检查双方的人脸，避免把不同的人合成一个人物。

::: warning 人物修正不会删除原始媒体
**移动到其他人物**只改变人脸属于哪个人物；**从该人物移除**只解除人脸与人物的关联。两种操作都不会修改原始媒体，也不会把媒体移入回收站。
:::

人物编辑窗口中的人脸面板用于修正识别关系；它不等同于当前图库范围下的媒体网格。跨资源库使用人物时，执行移动、移除或合并前要再次确认选中的人脸。

## 地点：在地图上查找媒体

### 使用地点地图

1. 打开**合集 → 地点**，或在合集首页的地点区域点击**地图**。
2. 选择**全部资源库**或某个具体资源库。
3. 拖动或缩放地图。地图会显示当前范围内带有 GPS 坐标的媒体；密集区域会合并为数字标记，点击后可以逐级放大。
4. 点击单个点查看缩略信息，再点击进入媒体查看器。

地图使用的是媒体已经登记的纬度和经度。没有 GPS 的媒体不会因为打开地图而自动获得位置；时间信息也不会单独生成地图点。

### 从地点进入行程

合集首页会把符合条件的一段地点和时间聚合显示为行程卡片。点击行程卡片可以查看该段时间和地理范围内的媒体。行程是为了回顾而计算出的视图，不是可以手动命名、移动媒体或单独备份的相册；如果元数据、地点聚类或时间范围改变，行程也可能改变。

## 事件：按时间和活动回顾

### 浏览事件列表

1. 打开**合集 → 事件**。
2. 每张事件卡片显示自动生成的名称、时间范围、封面和媒体数量。
3. 如果列表为空或结果明显过时，点击标题栏的**重新构建**，等待事件重建完成后再刷新列表。

事件列表只显示当前账户中处于活动状态且未隐藏的事件。隐藏事件后，它会从列表中消失；如果仍保留原详情地址，可以在详情页取消隐藏。

### 在事件详情中整理

打开一个事件后，可以使用以下操作：

- **重命名**：设置一个更容易识别的事件名称；
- **设为封面**：从选中的媒体中指定事件封面；
- **添加媒体**：从媒体选择器加入内容；
- **从事件中移除**：把选中的媒体排除出当前事件；
- **在所选媒体前拆分**：在时间顺序中的指定位置建立边界；
- **移动到其他事件**：把选中的媒体加入另一个事件；此操作需要输入目标事件 ID；
- **合并**：把多个事件合并到当前事件；
- **隐藏 / 取消隐藏**：控制事件是否出现在事件列表；
- **分享**：创建该事件的分享链接。

::: warning 事件调整可能需要重建
事件详情中的添加、移除、拆分和合并会写入人工约束。页面出现“更改正在等待事件重新构建”时，说明约束已保存，但自动分组尚未完成下一次发布。重建后应重新检查事件成员和封面。
:::

从事件中移除媒体只改变事件成员关系；媒体仍在资源库中。真正删除媒体时，请回到资源库浏览页，明确使用**移入回收站**。

## 没有结果时按顺序检查

1. 打开[状态页](./monitor)，确认元数据读取、人物识别和其他相关任务没有持续失败。
2. 如果人物识别已经完成但分组仍不正确，在[管理](./manage)页资源库区域顶部点击**重建人物识别**。这是跨资源库的重建操作，不需要逐个资源库执行。
3. 如果地图缺少本应有的位置，在对应资源库卡片的 **⋯** 菜单中点击**重建位置聚类**；它只重新计算地点标签，不会为没有 GPS 的媒体补写坐标。
4. 如果事件为空或明显过时，回到**合集 → 事件**，点击**重新构建**，等待提示消失后再检查结果。
5. 最后确认**图库范围**没有限制在另一个资源库，并确认文件的拍摄时间、GPS 和人脸派生任务已经完成。

## 三种视图的边界

| 操作 | 会改变什么 | 不会改变什么 |
| --- | --- | --- |
| 重命名人物或事件 | 显示名称和确认状态 | 原始媒体和文件路径 |
| 移动或移除人脸 | 人物与人脸的关联 | 原始媒体内容 |
| 隐藏人物或事件 | 默认列表中的可见性 | 媒体、文件和识别记录 |
| 重新构建人物/地点/事件 | 派生分组和聚类结果 | 原始媒体文件 |
| 查看地图或行程 | 当前浏览范围 | 数据库中的媒体文件位置 |

::: info 隐私提醒
人物、位置和拍摄时间都可能是敏感信息。创建公开分享前，先检查人物和地点范围，并用未登录窗口确认接收者实际看到的内容。
:::

需要了解跨资源库范围、分页、行程计算阈值、标签来源以及事件重建的详细规则，请阅读[相册与合集进阶](../help/collections-details)。
