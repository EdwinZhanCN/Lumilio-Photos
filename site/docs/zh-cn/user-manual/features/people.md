# 人物、地点与事件

这些视图依赖照片元数据或可选分析结果，因此可能晚于缩略图出现。

## 人物

<DocPath :items="['合集', '人物']" />

人物页按识别到的人脸分组。进入人物详情后，可以命名人物、检查分配的人脸，或把重复人物合并。识别会出错；合并前应先查看双方照片，涉及重要资料时不要只凭封面判断。

## 地点

<DocPath :items="['合集', '地图']" />

地图只显示包含可用位置元数据的媒体，并可按城市或行程进入详情。没有 GPS 信息的照片不会因为开启地图而被自动补上位置。

## 事件

<DocPath :items="['合集', '事件']" />

事件适合按时间段回顾拍摄内容。事件名称和聚合结果可以整理，但不会改变原始文件。

::: info 隐私提醒
人物、位置和拍摄时间都可能是敏感信息。创建公开分享前，先在接收者视角检查内容与可见信息。
:::
