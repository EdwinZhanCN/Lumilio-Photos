# 重复项、喜欢与回收站

**合集 → 工具**把清理和快捷视图放在一起。它们改变的是整理状态或回收站状态，不是存储位置；批量操作前先确认图库范围和受影响数量。

## 重复项：先审核，再合并

候选组来自**完全重复**（内容一致）和**视觉相似**（连拍、裁剪版、导出副本等）。

1. 打开候选组，逐项检查文件名、尺寸、格式、大小和元数据；
2. 点击要**保留**的项目；
3. 点**合并**：保留选中项，其余成员移入回收站。

> 相似不等于重复：不要只凭缩略图判断。连拍、RAW 与导出版可能都很像。确认不是重复时选**不是重复**进入已忽略。管理员需先在**管理**页对资源库执行**扫描重复项**才有新候选。

## 喜欢

资源库或查看器里点喜欢后，可在**工具 → 喜欢**集中浏览、搜索、分享和批量**取消喜欢**。喜欢不移动、不复制文件。

## 回收站：软删除的恢复入口

删除、批量操作和重复项合并都会把媒体移入回收站并从普通浏览隐藏。

1. 打开**工具 → 回收站**，进入选择模式选中要保留的；
2. 点**恢复**并确认；
3. 回资源库确认重新出现。

> 当前回收站只提供恢复，无 Web 端永久删除按钮。回收站不是备份：磁盘/数据库损坏、挂载丢失都不能靠它恢复。

## 智能分类

分类器运行时，工具页会显示**文档、收据、插画**等入口，按 AI 来源标签筛选。关闭 Lumen Intelligence 后这些结果不再生成，但相册、标签、喜欢和回收站不受影响。
