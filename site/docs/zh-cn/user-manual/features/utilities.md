# 重复项、喜欢与回收站

<DocPath :items="['侧边栏', '合集', '工具']" />

**工具**把清理和快捷视图放在一起。它们改变的是媒体的整理状态或回收站状态，不是新的存储位置；执行合并、删除和批量操作前，先确认当前的**图库范围**和受影响数量。

## 重复项：先审核，再合并

重复项页面按资源库范围显示候选组。候选可能来自：

- **完全重复**：内容一致，通常最适合自动判断；
- **视觉相似**：感知哈希相近，连拍、裁剪版本和导出副本都可能被列出；
- **混合**：同一组中同时存在完全重复和视觉相似关系。

打开候选组后，逐项检查文件名、尺寸、格式、大小和元数据，点击要保留的项目，再选择**合并**。合并会保留选中的项目，把其他成员的可合并元数据合并到它，并把其余成员移入回收站；它不是立即抹除文件。

如果确认不是重复，选择**不是重复**，该组会进入**已忽略**。**待处理、已合并、已忽略**三个状态可以分别查看。管理员需要先在**管理**页对某个资源库执行**扫描重复项**，工具页才会有新的候选。

::: danger 相似不等于重复
不要只凭缩略图选择保留项。连拍、同一场景的不同版本、RAW 与导出图像可能都很相似；合并前应确认原始文件、编辑版本和重要元数据都在预期项目上。
:::

## 喜欢：一种可逆的快捷标记

在资源库或查看器中点击喜欢后，可以从**合集 → 工具 → 喜欢**集中浏览。喜欢页仍是普通资源浏览器，可以搜索、筛选、分享和批量选择；特有的批量操作是**取消喜欢**。喜欢不会移动文件，也不会复制媒体。

## 回收站：软删除后的恢复入口

资源库批量操作、查看器删除以及重复项合并都会把媒体标记为已删除，并从普通浏览中隐藏。打开**合集 → 工具 → 回收站**后可以：

1. 进入选择模式，选中需要保留的项目；
2. 点击**恢复**并确认；
3. 恢复完成后回到资源库检查其是否重新出现。

当前回收站页面只提供恢复，不提供从 Web 端永久删除或清空的按钮。回收站也不是备份：磁盘损坏、数据库损坏或资源库挂载丢失都不能靠回收站恢复。

## 智能分类：用于缩小范围

当可用的分类器已经运行时，工具页会显示**文档、收据、插画**等入口。它们按 AI 来源标签筛选媒体，适合快速找到一类内容，再进行人工确认或分享。关闭 Lumen AI 后，这些分类结果不会继续生成；相册、文件夹、手动标签、喜欢和回收站仍可使用。

更多重复检测版本、合并的软删除边界、回收站与文件系统的关系见[工具进阶](../help/utilities-details)。
