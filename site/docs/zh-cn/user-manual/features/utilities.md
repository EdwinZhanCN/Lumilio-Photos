# 重复项、收藏与回收站

<DocPath :items="['合集', '实用工具']" />

## 重复项

重复项视图按内容与分析结果给出候选组。先展开一组检查分辨率、格式和元数据，再决定保留哪个文件。相似照片不一定是重复文件，连拍、编辑版本与导出副本尤其需要人工判断。

## 收藏

在资源库或查看器中标记“喜欢”后，可以从 **合集 → 收藏** 集中查看。收藏只是组织状态，不会移动文件。

## 回收站

删除的媒体进入 **合集 → 回收站**。需要恢复时，在清空或永久删除前完成；回收站不是备份，也不保证抵御磁盘损坏或数据库丢失。

## 智能分类

可用的分类器会显示为额外工具。结果适合快速缩小范围，但不应作为删除原始媒体的唯一依据。关闭 Lumen 后，基本的相册、标签、收藏与文件夹功能仍可使用。
