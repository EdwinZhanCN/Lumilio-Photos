# 可选的 Lumen 与 Lumilio Agent

Lumen 提供本地 ML 能力，例如语义嵌入、OCR、人脸与分类任务；Lumilio Agent 则在这些能力和资源库上下文之上提供对话与画板式工作流。两者都是增强功能，不是管理原始照片的前提。

## 在 Desktop 启用 Lumen

<DocPath :items="['Desktop 控制面板', 'Lumen']" />

选择适合设备的预设、后端和模型缓存位置后保存。首次启动会在后台下载模型，控制面板会显示下载、加载、预热、就绪或失败阶段。更换缓存位置可能移动大量数据，并暂停 Hub。

## 判断是否可用

管理员可在 **状态** 页查看语义图像、语义文本、分类、OCR 与人脸等能力。单项不可用不代表资源库损坏；它只会影响依赖该能力的搜索或整理结果。

## 使用 Agent

Agent 可从浮动入口或独立页面打开，并可引用人物、相册、固定视图、相机或镜头等上下文。把回答当作辅助结果，执行批量整理或删除前仍要核对实际选择范围。

::: info 资源与隐私
本地模型会占用磁盘、内存和算力。是否完全留在本机取决于你配置的后端与外部服务；启用任何远程提供商前，请阅读其隐私与费用条款。
:::
