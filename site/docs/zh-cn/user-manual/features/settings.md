# 账户、用户与偏好

<DocPath :items="['侧边栏', '设置']" />

设置页按当前版本提供的标签管理账户、安全、外观、用户和服务连接。普通用户只会看到自己有权限修改的内容。

## 账户与安全

可以修改个人资料、头像、密码、验证器和通行密钥。更换双重验证方式前，先确认另一种方式或恢复代码可用，避免把自己锁在账户外。

## 用户管理

管理员可以创建和管理家庭成员或其他用户。遵循最小权限：只有需要管理存储、用户和服务状态的人才应成为管理员。

## 外观与语言

主题可以跟随系统，也可以固定为亮色或暗色。外观偏好保存在当前浏览器中，因此换浏览器或清理站点数据后可能需要重新设置。

## 云与外部服务

连接外部服务时，先确认授权范围、费用和数据流向。断开连接不会自动删除对方已经保存的数据；删除本地连接配置也不等于撤销提供商侧的授权。

::: info Desktop 运行设置在另一个窗口
存储位置、Lumen 安装、日志和需要重启的 Server 配置位于 Desktop 控制面板，不在照片主界面的设置页。
:::
