# 账户、用户与偏好

**设置**页按标签组织。账户和外观人人可用；**AI** 和**用户管理**只对管理员显示。

## 账户：先保护登录

- 修改显示名称、头像（从已有媒体选，不复制原始文件）；
- 修改密码（成功后当前会话退出，需重新登录）；
- 启用/停用 TOTP 验证器，查看并重新生成恢复码；
- 注册/移除通行密钥（需先启用 TOTP，且浏览器支持安全上下文）。

换登录方式前，先确认另一种方式仍可用；重新生成恢复码后旧码立即失效。

## 外观：只影响当前浏览器

语言地区、亮暗主题、资源页布局（舒展/紧凑及列数）。换浏览器需重新设置，不影响媒体和他人。

## 云导入：只管理凭据

添加凭证并完成验证后变成**已连接**。**断开**保留记录停止会话；**移除**删除本地凭据，已导入的媒体不受影响。凭据本身不会自动导入内容——需要在创建资源库或资源库卡片上发起导入。

::: warning
云账号密码只在受信任的流明集页面输入。移除本地凭据不等于撤销云服务商侧的授权。
:::

## Server：运行信息与数据库备份

- **健康检查间隔**：浏览器多久检查一次 Server 在线（1–50 秒）；
- **数据库备份**：自动/立即创建、下载、恢复、删除快照；
- **运行时配置**：只读展示当前 TOML 解析结果。

恢复是异步操作，详见[备份与数据完整性](../introduction/integrity)。运行时配置不能在 Web 编辑；Desktop 的相关项在控制面板管理。

## AI：管理员配置可选能力

**AI** 标签管理两类独立能力，都要求**显式选择**，不存在默认回退。

### Lumilio Agent 的 LLM 提供方

1. **显式选择提供方**：未选择/未知/为空 = 未配置，不会回退到任何默认服务；
2. 填写模型名称。**DeepSeek、Ollama 等 OpenAI 兼容提供方必须填 Base URL**；**远端提供方需要 API Key**；
3. **验证连接**：只验证当前未保存的草稿，验证失败不会保存任何内容；
4. **切换提供方需重新提供 secret**：已保存的密钥只属于原提供方；
5. **「启用 Lumilio Agent」和「验证提供方」是两个动作**：启用只改可用状态，验证只查连接；服务端启用前还会再做一次结构完整性检查。

### 媒体理解任务（Lumen Intelligence）

分别开关图像语义分析、视频语义、BioCLIP物种识别、OCR文字识别和人物识别。视频语义依赖图像语义分析，关父项一并关闭。关闭不会删除已有索引；重新启用后到[状态页](./monitor)按需重建。

节点本身的安装与再配置在 Desktop 控制面板、`lumen-cli configure` 或 Docker 中完成，见 [Lumen Intelligence](./lumen-intelligence)。

## 用户管理：管理员

选择账户可修改用户名、头像、**用户/管理员**角色和活跃状态。没有「删除用户」操作；停用阻止登录但不删媒体。

其他用户丢失全部登录因子时，用**重置访问权限**生成一次性临时密码（会清除对方的 TOTP、恢复码和通行密钥），通过安全渠道传递并提醒立即重设。管理员不能用此按钮重置自己。
