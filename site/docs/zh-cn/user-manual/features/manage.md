# 把照片加入资源库

<DocPath :items="['侧边栏', '管理']" />

**管理**页是导入入口。先在页面顶部确认当前资源库，再选择上传或扫描来源。

## 上传

选择照片或视频后，应用会先计算文件指纹，再提交到服务器处理。保持页面打开，直到上传队列明确显示完成或失败。失败项目可以重试；不要因为进度暂时不动就重复选择同一批文件。

## 扫描

扫描用于已经位于服务器可访问目录中的媒体。它不会让浏览器任意读取你的电脑；Server 只能访问部署时允许的路径，Desktop 只能访问你明确授权的位置。

## 导入后发生什么

媒体会依次经历登记、元数据读取、缩略图和可选分析。照片可能先出现在资源库中，随后才补齐缩略图、人物或语义结果。可在[状态页](./monitor)区分“仍在处理”和“处理失败”。

::: tip 先小批量验证
第一次接入新相机、手机导出目录或外接盘时，先导入少量文件，确认时间、方向与重复项策略符合预期，再处理完整资料。
:::
