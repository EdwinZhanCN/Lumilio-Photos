# 把媒体加入资源库

在**管理**页把媒体登记进资源库。先选对导入方式，再确认目标资源库。

## 选哪种导入方式

判断标准只有一个：**运行流明集的主机能不能直接读取文件**。

| 文件现在在哪里 | 用哪种方式 | 文件最终在哪里 |
| --- | --- | --- |
| 当前设备浏览器能选到 | **上传** | `inbox/`，按存储策略归档 |
| 主机上已有的目录（已授权/已挂载） | **扫描** | 留在原位置，只登记 |
| 已连接的云服务 | **云导入** | `inbox/`，按存储策略归档 |

## 上传（适合小批量、跨设备）

1. 打开**管理**页，在**上传目标**中选择资源库。
2. 拖入文件（支持图像含 RAW、视频、音频），点击**上传**。
3. 等待队列项变为**已完成**、**重复项**或**失败**。

**成功标志**：队列显示已完成，媒体出现在资源库中。
**失败恢复**：失败文件保留在待上传队列，修复网络/磁盘问题后重新点击上传即可。
**数据边界**：上传只发送你选择的文件，不会授权服务器读取设备上的其他目录。

> 重复项 = 内容指纹一致，第二份不会占用空间。首次导入新相机/新目录时，先用小批量验证。

## 扫描（适合大批量、主机上的文件）

1. 把文件放到资源库**自由区**（资源库根目录下，除 `inbox/` 和 `.lumilio/` 之外的目录）。
2. 等待复制完成，在资源库卡片 **⋯** 菜单选择**重新扫描**。

**成功标志**：媒体出现在资源库中。
**注意**：扫描不移动文件；`inbox/` 和 `.lumilio/` 是受保护目录，扫描会跳过，也不要手动往里放文件。

## 云导入

1. 先在**设置 → 云导入**添加凭证并完成验证。
2. 创建资源库时选择云端来源，或在已绑定凭据的资源库卡片选**从云端导入**。

> iCloud 导入依赖 Apple 非官方行为，属于实验功能，可能随时失效，见[测试版与可选功能](../introduction/experimental)。

## 创建资源库（管理员）

在**管理**页点**添加资源库**，一次性确定：

1. **存储位置**：Desktop 从控制面板已登记的位置选择；Server 使用已挂载的位置。
2. **名称**：普通资源库的名称就是目录名（1–80 字符，可用文字、数字、空格、`-`、`_`）。
3. **文件布局**：`date`（按年月，默认）、`flat`（inbox 根目录）或 `cas`（按内容哈希分层）。
4. **同名冲突处理**：`rename`（默认，冲突时安全重命名）或 `uuid`（追加短 UUID）。**任何策略都不会替换已有原件**。

创建后名称、布局和冲突策略都不能修改，也不能从应用内删除资源库——创建前确认清楚。

## 导入后检查什么

- 队列仍在运行且完成数在增加：等待，不要重复上传或扫描；
- 媒体显示为重复项：目标资源库选错或确实已存在，通常无需再次导入；
- 失败数持续增加：检查磁盘在线、目录可写、空间充足，再到[状态页](./monitor)看具体错误。
