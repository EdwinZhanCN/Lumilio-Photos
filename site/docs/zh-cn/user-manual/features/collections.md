# 相册与合集

**合集**是组织和浏览入口，不是新的存储位置：同一媒体可以同时出现在相册、标签、人物和事件中，原始文件不被复制或移动。

## 先选入口

| 你想做什么 | 入口 |
| --- | --- |
| 手动整理一组媒体 | **相册**（自己维护成员） |
| 按现有目录找媒体 | **文件夹**（直接反映来源路径） |
| 给跨目录媒体加主题 | **标签**（区分手动与 AI 来源） |
| 按人/位置/时间回顾 | **人物**、**地点**、**事件**（自动生成，可人工修正） |
| 清理、恢复、分享 | **工具**（喜欢、重复项、回收站、分享链接） |

**判断标准**：只有相册、手动标签、喜欢状态和事件的人工修正会写入整理状态；文件夹、地点、人物是依据已登记信息生成的视图。

## 相册：手动整理

**创建**：合集 → 相册 → **新建相册**，填名称、选封面（新建时必须选），需要时打开**生物图鉴**，点**创建相册**。然后到资源库选择媒体，用**添加到相册**加入成员。

**维护**：打开相册可编辑名称/描述/封面；选择模式中**从当前相册移除**批量解除成员；列表中选择模式可批量删除相册。

> 移除成员或删除相册都**不会删除媒体**。删除媒体请到资源库用**移入回收站**。

## 文件夹

按资源库分组显示目录、数量、日期范围和封面；详情页包含子目录。文件系统里移动媒体并重新扫描后，文件夹视图随之更新。

## 标签

位于**合集 → 工具 → 标签**：按名称搜索，按**手动/AI**来源筛选。资源库中添加的标签属手动来源；AI 标签由分类器维护，用于筛选和发现，不等同于人工确认。

## 工具：清理与快捷视图

- **喜欢**：集中查看并批量取消喜欢；
- **重复项**：审核候选组后选择保留项**合并**（其余移入回收站）；
- **回收站**：恢复软删除的媒体；
- **分享链接**：集中检查、延期或撤销已创建链接；
- **文档、收据、插画**：按 AI 分类结果浏览。

> 合集依赖数据库关系，不是备份。删除相册不会产生可恢复副本；批量操作前核对受影响数量。
