# 相册与合集

<DocPath :items="['侧边栏', '合集']" />

合集把同一资源库的不同组织方式放在一个入口：相册、事件、地图、人物、文件夹、标签和实用工具。顶部的资源库范围会影响你看到的内容。

## 相册

创建相册后，可以从资源库批量加入照片，也可以在单张查看器中加入。打开相册可修改信息、调整内容、分享或删除相册。删除相册不应被理解为删除其中的原始媒体；最终以确认框说明为准。

## 文件夹与标签

文件夹视图反映媒体的来源路径，适合按现有目录定位；标签是你主动维护的跨目录分类。二者解决的问题不同，不必为了使用 Lumilio 重做原来的文件夹结构。

## 事件

事件把一段时间内的媒体聚合成可浏览的组。你可以打开事件查看内容、修改事件信息或创建分享。自动聚合结果应当视为整理建议，而不是原始文件结构。
