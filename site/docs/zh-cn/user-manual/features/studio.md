# 在工作室编辑照片

<DocPath :items="['侧边栏', '工作室']" />

工作室用于在浏览器中完成裁剪、调整、文字等编辑，并导出 JPEG、PNG 或 WebP。编辑过程围绕当前项目进行，导出会生成新文件，不应覆盖资源库中的原始媒体。

## 基本流程

1. 进入工作室并选择照片；
2. 完成画面、颜色或文字调整；
3. 预览最终尺寸与透明区域；
4. 在导出面板选择格式、质量和文件名；
5. 下载结果并在目标应用中检查。

JPEG 适合普通照片；PNG 适合需要无损或透明背景的内容；WebP 通常能兼顾体积与画质，但使用前应确认接收方支持。

::: warning 离开前先导出
工作室中的临时编辑状态不等于已经保存到资源库。刷新页面、切换设备或清理浏览器数据前，先导出需要保留的结果。
:::
