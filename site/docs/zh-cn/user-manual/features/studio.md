# 在工作室编辑静态媒体

工作室对**图像**做非破坏性编辑：**保存**写入编辑指令（sidecar），**导出**才生成新文件。**原始媒体永远不会被覆盖。**

## 开始编辑

1. 打开**工作室**，点**打开编辑器**，选择一项图像媒体；
2. 用右侧面板编辑：
   - **调整**：曝光、对比度、高光、阴影、色温、饱和度、锐度、降噪等；
   - **裁剪**：自由裁剪或宽高比预设，可旋转/翻转；
   - **边框**：纯色、渐变、毛玻璃、留白、圆角、暗角、相机信息条；
   - **文字**：多个文字图层，字体/字号/颜色/描边/阴影/位置，可选场景深度遮挡（需 WebGPU）；
3. 点**保存**保留编辑指令，或点**导出**生成新文件。

**成功标志**：保存后下次打开同一媒体会重新读取编辑；导出下载到 `-lumilio` 后缀的新文件（JPEG/PNG/WebP，可选质量与尺寸）。

**未保存的提示**：预览里的改动和已保存的指令是两回事。切换媒体、刷新或关闭前先点**保存**或**导出**。

**恢复**：编辑器内**撤销**/**全部重置**只作用于当前会话；清空「最近编辑」列表不删除已保存的指令或原始媒体。
