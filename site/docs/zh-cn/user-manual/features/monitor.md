# 检查任务与服务状态

<DocPath :items="['侧边栏', '状态']" />

状态页只对管理员显示。它用于判断系统是在正常处理、空闲，还是需要人工介入。

## 先看三件事

1. **连接状态**：侧边栏状态点是否在线；
2. **队列摘要**：任务是运行中、已稳定、空闲还是需要注意；
3. **能力状态**：存储、数据库和各项 ML 能力是否可用。

照片已出现但缩略图或人物结果尚未出现，通常表示后续任务仍在排队。只有在失败计数持续增长、同一任务重复失败或队列长期无进展时，才需要进一步查看日志。

| 你看到的状态 | 先做什么 |
| --- | --- |
| 队列仍在运行，完成数持续增加 | 等待处理结束，不要重复扫描 |
| 队列空闲，但个别缩略图缺失 | 重新打开该媒体；仍缺失时记录文件类型并请管理员检查任务 |
| 失败数增加 | 检查存储设备是否在线、可写且有剩余空间，再查看失败任务或日志 |
| 侧边栏显示离线 | Desktop 用户打开控制面板检查 Server；Server 用户联系部署管理员 |
| 只有人物、OCR 或语义结果缺失 | 检查对应 ML 能力；缩略图本身不依赖 Lumen |

普通用户看不到状态页时，把出现问题的媒体、发生时间和界面错误交给管理员；不要通过反复导入同一批文件来试探。

## Desktop 的进一步检查

打开 Desktop 控制面板，查看 Server 与 Lumen 卡片的阶段和错误，再按来源查看受限日志尾部。修改运行配置后，Desktop 会先严格校验并尝试启动；失败时可恢复到上一个可用配置。

::: danger 不要用“重启”代替诊断
反复重启可能掩盖路径不可写、磁盘已断开或模型下载失败。先记录错误、确认受影响子系统，再重试对应操作。
:::
