# 浏览、筛选与批量操作

<DocPath :items="['侧边栏', '资源库']" />

资源库是日常使用的中心。顶部可以切换资源库范围、按拍摄时间或最近加入排序，也可以进入选择模式。

## 找到需要的照片

- 从首页搜索开始，或在资源库应用筛选条件；
- 需要恢复或分享当前视图时，保留页面 URL；
- 点击缩略图进入查看器，前后切换不会丢失当前列表位置；
- 在信息面板查看基础信息、元数据和标签。

## 批量整理

进入 **选择** 后，可以评分、喜欢或取消喜欢、添加标签、加入相册、堆叠、下载或删除。菜单会说明操作影响“选中项目”还是它们所代表的全部资源。

::: warning 删除前确认范围
删除与移出相册是不同操作。前者会进入回收站流程，后者只改变相册成员。对堆叠或多资源项目操作时，留意确认框中的实际数量。
:::

## 视图与性能

缩略图仍在生成时会逐步出现。大量媒体首次处理需要时间；如果长时间没有变化，到[状态页](./monitor)检查队列，不要通过反复扫描制造重复任务。
