# 浏览、筛选与批量操作

资源库页的路径：**先确定范围，再搜索或筛选，最后查看或批量处理**。

## 找媒体

1. 顶部**图库范围**选**全部资源库**或某个资源库。
2. 快速定位用右下角**搜索框**；精确缩小范围用**筛选器**。
3. 按**拍摄时间**或**最近添加**排序，按日期分组浏览。
4. 单击缩略图打开查看器；要批量整理时进入**选择模式**。

> **搜索无结果**：先确认图库范围，再清空筛选或换搜索词。搜索可能依赖 OCR/语义索引，若提示「图像语义分析暂不可用」，结果会退回文字匹配——到[状态页](./monitor)确认任务状态。

## 筛选

点击**筛选按钮**，设置条件后点**应用**。已启用条件显示为标题栏标签，可点 × 移除或点**重置**全部清除。

| 筛选区域 | 可以筛选什么 |
| --- | --- |
| 类型 | 图像 / 视频 |
| 喜欢 / 评分 | 喜欢状态、1–5 星 |
| 媒体构成 | 含 RAW、JPEG+RAW、实况媒体等 |
| 分组 | 未分组、堆叠、连拍、手动堆叠 |
| 文件名 / 标签 | 文件名匹配、已有标签 |
| 日期 / 位置 | 起止日期；GPS 边界框或半径 |
| 相机与镜头 | 当前资源库中已有的元数据选项 |

多个区域叠加缩小结果；多标签需同时具备。「未分组」不能与堆叠类型同时使用。

## 批量操作

进入**选择模式**：单击选中，Ctrl/Command 单击切换单项，Shift 单击选连续范围，Ctrl/Command+A 全选当前页。

**操作**菜单提供：设置评分、喜欢/取消喜欢、添加标签、添加到相册、堆叠所选、下载全部（多数量时打包 ZIP）、分享、移入回收站。

::: danger 提交前确认数量
堆叠在选择计数中可能显示 1 项，但确认框会显示实际影响的资源数量。删除、合并前务必核对影响范围。
:::

**移入回收站**是软删除，可在**合集 → 工具 → 回收站**恢复；它不是立即永久删除。

## 结果不完整时

1. 检查图库范围是否选错；
2. 移除筛选标签或重置；
3. 清除搜索词对比；
4. 刚上传/扫描的媒体先到[状态页](./monitor)等索引任务完成，不要反复上传。
