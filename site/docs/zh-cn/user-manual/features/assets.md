# 浏览、筛选与批量操作

<DocPath :items="['侧边栏', '资源库']" />

资源库页把日常操作串成一条路径：**先确定范围，再搜索或筛选，最后查看或批量处理**。页面展示的是“逻辑媒体项”，而不是简单地把磁盘上的每一个文件列出来。一个媒体项可能由 JPEG 与 RAW、实况片段等多个组成文件构成；堆叠则是另一层展示分组。

## 先用这条路径找到媒体

1. 在顶部的**图库范围**中选择**全部资源库**，或选择一个具体资源库。
2. 需要快速定位时，打开右下角的搜索框输入文字；需要精确缩小范围时，打开筛选器。
3. 用**拍摄时间**或**最近添加**排序，再按日期分组浏览。
4. 单击缩略图打开查看器；需要一起整理多个项目时，进入**选择模式**。

::: tip 先从范围开始
同一个搜索词在不同资源库中可能得到完全不同的结果。出现“没有结果”时，先确认顶部的**图库范围**，再清除筛选条件或更换搜索词。
:::

## 选择浏览范围

顶部的**图库范围**提供两种选择：

- **全部资源库**：合并当前账号可见的资源库；
- **某个资源库**：只查询该资源库中的媒体。

范围选择会保存为当前浏览器的偏好，切换到其他页面后通常仍会保留。它不是 URL 的一部分，因此复制页面链接给别人时，还需要告诉对方选择同一个资源库范围。

相册、人物、文件夹、标签等专题页面会在资源库范围之外再加一层专题条件。有些筛选项会显示为**此视图已锁定**，这是页面的固定范围，不能在筛选器中移除。

## 浏览与查看

### 排序和日期分组

在桌面端直接打开排序菜单；在窄屏设备上打开右上角的**更多操作**：

- **拍摄时间**：优先使用媒体的拍摄时间，没有拍摄时间时使用加入时间；
- **最近添加**：按加入资源库的时间排序。

主视图会按当前界面的日期格式把项目分成**今天、昨天、本周、本月**和月份。排序只改变当前结果的排列方式，不会移动原始文件。

### 缩略图和查看器

- 普通模式下单击缩略图会打开查看器；在查看器中前后切换，当前搜索、筛选和排序仍会保留。
- 堆叠缩略图右下角的数字表示堆叠中的项目数量。单击数字可以打开堆叠浏览器，查看组内成员；单击其他区域仍然打开当前代表项目。
- 资源仍在后台生成缩略图、视频或音频派生文件时，网格会先显示占位内容，完成后逐步替换。

可以在**设置 → 外观 → 资源页面**选择**舒展**或**紧凑**布局；紧凑布局还可以调整每行列数。大量媒体时页面会按需加载，滚动到底部才会继续请求下一批结果。

## 搜索

1. 点击右下角的搜索按钮。
2. 输入文件名、地点、文字内容或自然语言描述，等待结果刷新；也可以按 Enter 立即提交。
3. 需要结束搜索时，点击输入框中的 **×** 清除文字，或点击红色关闭按钮。

查询结果较多时，页面会先显示**最佳结果**，下方再显示完整的**结果**列表。最佳结果用于快速确认“最像”的项目，完整结果仍可按当前排序继续浏览。

::: warning 搜索依赖后台索引
搜索可能同时利用文件名、OCR文字识别、地点和可选的图像语义分析索引。若页面提示“图像语义分析暂不可用”，结果会退回可用的文字匹配，可能不完整；这不是媒体丢失。请到[状态页](./monitor)确认相关任务是否仍在处理。
:::

## 筛选

点击标题栏的**筛选按钮**打开筛选器；按钮右上角会显示已启用条件的数量。桌面端和移动端都需要点击面板底部的**应用**，筛选器关闭不会自动应用尚未提交的改动。已启用的条件会显示为标题栏中的标签，点击标签上的 **×** 可以移除单项；点击**重置**可以清除所有可编辑条件。

| 筛选区域 | 可以筛选什么 |
| --- | --- |
| 类型 | 图像或视频 |
| 喜欢 | 已喜欢、未喜欢 |
| 评分 | 1–5 星，或未评分 |
| 媒体构成 | 含 RAW、JPEG+RAW、RAW 未配对、不含 RAW、实况媒体 |
| 分组 | 未分组、所有堆叠、连拍、手动堆叠 |
| 文件名 | 包含、匹配、开头是、结尾是 |
| 日期 | 设置起始日期、结束日期，或两者同时设置 |
| 位置 | 输入经纬度边界框，或在地图上用中心点和半径生成范围 |
| 相机品牌与镜头 | 从当前资源库中已有的元数据选项中选择 |
| 标签 | 搜索并选择一个或多个标签 |

多个筛选区域会一起缩小结果；选择多个标签时，媒体需要同时具有这些标签。位置筛选只匹配带有 GPS 坐标的媒体。筛选“媒体构成”针对一个逻辑媒体项的组成文件，不等同于对某一个文件名进行筛选。

::: warning 堆叠筛选的组合限制
“未分组”不能和“连拍”或“手动堆叠”同时使用。选择未分组后，界面会清除堆叠类型；如果从旧链接或其他客户端发来矛盾组合，Server 会拒绝该请求。
:::

## 批量操作

### 进入选择模式

点击标题栏的**选择模式**按钮，缩略图右上角会出现选择标记。此时：

- 单击项目以选中它；如果要切换单项而不清空其他选择，请使用 Ctrl/Command 单击；
- 按住 **Ctrl**（Windows/Linux）或 **Command**（macOS）单击，可以切换单项而不清空其他选择；
- 按住 **Shift** 单击，可以选中连续范围；
- 在网格获得焦点后，按 **Ctrl/Command + A** 会选中当前已经加载到页面的项目；按 **Esc** 清空选择。

选择数量显示的是**浏览项目**数量。选中堆叠时，菜单和确认窗口会另外显示它实际会影响的资源数量。

### 可用操作

打开带火箭图标的**操作**菜单，根据当前页面可见的动作执行：

| 操作 | 作用 |
| --- | --- |
| 设置评分 | 为所选资源设置 1–5 星，或改为未评分；提交前会再次确认 |
| 喜欢 / 取消喜欢 | 批量更新喜欢状态；提交前会再次确认 |
| 添加标签 | 选择已有标签，或输入名称创建新标签后应用 |
| 添加到相册 | 从相册列表中选择目标相册；不会移动原始文件 |
| 堆叠所选 | 将至少两个受影响的资源组成一个手动堆叠 |
| 下载全部 | 下载所选资源的原始文件；数量较多时会生成 ZIP |
| 分享 | 打开分享链接表单，可设置标题、有效期和下载权限 |
| 移入回收站 | 将所选资源移入回收站，而不是立即永久删除 |

专题页面可能提供额外动作。例如，在相册详情页中，**从当前相册移除**只改变相册成员关系，不会删除资源库中的原始媒体；页面也可能隐藏不适用的动作。

::: danger 删除前确认影响范围
删除、下载、评分、喜欢、标签、相册和堆叠操作都可能按“受影响资源数量”执行。一个堆叠在选择计数中可能是 1 个项目，但确认框会显示它包含的多个成员。确认数量和范围无误后再提交。
:::

移入回收站后的媒体可以在**合集 → 回收站**中恢复或进一步处理；回收站的具体行为见[重复项、喜欢与回收站](./utilities)。

## 没有结果或结果不完整时

按下面顺序排查：

1. 检查**图库范围**是否选成了另一个资源库。
2. 查看标题栏的筛选标签，先点击 **×** 移除筛选，或点击**重置**。
3. 清除搜索词；如果清除后有结果，说明问题在搜索词或搜索索引，而不是浏览范围。
4. 检查堆叠缩略图上的“匹配数 / 总数”；筛选可能只命中堆叠中的部分成员。
5. 如果媒体刚上传或刚扫描，先到[状态页](./monitor)等待元数据和索引任务完成；不要反复上传或扫描同一批文件。

需要了解 URL 参数、搜索降级、分页、筛选器的组合规则以及批量操作的实际请求边界，请阅读[浏览与搜索进阶](../help/browse-details)。
