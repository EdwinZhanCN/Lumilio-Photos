# 创建与管理分享链接

你可以从相册、事件、人物详情或选中的媒体创建分享。接收者通过公开链接打开内容，不需要先完成你的服务器首次设置或登录。

## 分享前

1. 检查选中范围，尤其是相册和人物页中的全部内容；
2. 确认链接是否设置到期时间或其他限制；
3. 用未登录窗口打开链接，检查接收者实际看到的页面；
4. 再把链接发给对方。

<DocPath :items="['合集', '实用工具', '分享链接']" />

**分享链接**页集中显示已创建的链接，可复制、检查或撤销。撤销后，已经由接收者下载的文件无法远程收回。

::: warning 公开链接就是访问凭证
不要在公开频道发布包含私人照片的链接。怀疑链接泄露时立即撤销，并重新创建新的分享。
:::
