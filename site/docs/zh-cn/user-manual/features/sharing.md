# 创建与管理分享链接

分享链接让没有 Lumilio 账户的人直接查看一组媒体。接收者访问的是独立的公开页面，不需要登录，也不需要完成你的首次设置；因此链接本身就是访问凭证。

## 可以从哪里发起分享

当前可以从以下位置创建链接：

- 资源库浏览页或查看器中的单项、选中项目；
- 相册详情页中的整个相册或选中项目；
- 人物详情页中的人物集合或选中项目；
- **喜欢**、文档、收据、插画等工具结果中的选中项目；
- 事件详情页中的事件（事件使用自己的分享按钮）。

从一个动态视图（例如人物或相册）分享时，Server 会在创建时解析并保存一份**快照**。之后视图再新增的媒体不会自动加入已经创建的链接。

## 创建链接

1. 先检查当前页面的资源库范围、固定条件和选择数量；
2. 点击**分享**，输入容易识别的**标题**；
3. 选择有效期：7 天、30 天或 90 天；
4. 默认关闭下载。确实需要接收者保存文件时，再打开**允许下载**；
5. 只有在允许下载后，才可以选择**包含原始文件**；
6. 点击**创建链接**，立即复制成功对话框中的完整 URL。

创建成功后，原始令牌只在这个对话框中显示一次。关闭后，**分享链接**管理页只显示标题、来源、数量、访问次数和到期时间，不会再次显示或生成同一个 URL；丢失链接只能撤销后重新创建。

::: warning 公开链接不等于“只给某个人看”
不要把包含私人媒体的 URL 放在公开群组、工单或日志中。发送前用未登录的隐私窗口打开一次，确认标题、数量、视频/音频播放和下载策略都符合预期。
:::

## 管理已经创建的链接

打开**合集 → 工具 → 分享链接**，可以按**有效、已过期、已撤销**筛选：

- 有效链接：可以**延期 30 天**或**撤销**；
- 已过期或已撤销链接：可以从管理列表**删除记录**；
- 表格会显示来源、快照中的项目数、创建时间、到期时间、最后访问和访问次数。

撤销会立即阻止新的公开访问；延期只改变到期时间，不会改变快照内容。已经被接收者下载或另行保存的文件无法远程收回。

## 接收者能看到什么

公开页面只返回标题、描述、项目数量和公开媒体内容，不显示资源库路径、所有者信息或内部文件名。图像以缩略图和查看器展示，视频和音频提供浏览器播放；只有同时满足“允许下载”和“包含原始文件”时，查看器才提供原始文件下载。

链接失效通常表示已到期或被撤销。重新创建链接不会复活旧令牌，也不会改变原始媒体。

事件分享受事件项目数上限约束；当事件过大时，界面会禁用分享按钮。要分享较小范围，请在事件详情中选择媒体后使用普通的选中项目分享。

更深入的快照、令牌、状态转换和服务端限制见[分享链接进阶](../help/sharing-details)。
