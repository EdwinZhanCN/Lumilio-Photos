# 创建与管理分享链接

分享链接让没有流明集账户的人直接查看一组媒体。**链接本身就是访问凭证**——别把含私人媒体的链接发到公开场合。

## 创建链接

可以从资源库、查看器、相册、人物、事件或工具结果发起分享。

1. 先确认当前页面的范围和选中数量；
2. 点**分享**，输入**标题**；
3. 选择有效期：7 / 30 / 90 天；
4. **默认关闭下载**；确实需要时打开**允许下载**（之后才可选择**包含原始文件**）；
5. 点**创建链接**，立即复制完整 URL。

**成功标志**：对话框显示链接，接收者无需登录即可打开。
**注意**：令牌只在创建时显示一次；丢失后只能撤销重建。从动态视图（人物/相册）分享时创建的是**快照**，之后新增的媒体不会自动加入。

::: warning 发送前自检
用未登录的隐私窗口打开一次，确认标题、数量、播放和下载策略符合预期。
:::

## 管理链接

**合集 → 工具 → 分享链接**：按**有效/已过期/已撤销**筛选。

- 有效：**延期 30 天**或**撤销**（立即阻止新的公开访问）；
- 已过期/已撤销：**删除记录**；
- 已下载或另存的文件无法远程收回。

## 接收者能看到什么

标题、描述、数量、媒体内容和播放器；**不显示**资源库路径、所有者信息或内部文件名。只有同时开启「允许下载 + 包含原始文件」时才提供原文件下载。

**数据边界**：分享即把媒体内容放到公开页面，等价于把文件发给对方。
