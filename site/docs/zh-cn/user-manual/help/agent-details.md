# Lumilio Agent 进阶

日常使用方式见 [Lumilio Agent](../features/agent)。本页说明 Lumilio Agent 为什么会先返回结果集，以及哪些操作必须等待确认。

## 引用与结果集

Lumilio Agent 会根据当前用户、对话线程和已授权资源库创建引用（ref），再由界面加载引用指向的媒体。引用不是新的资源库，也不会扩大用户已经拥有的访问范围。

结果集适合当作一次查询的工作快照：新导入、删除、恢复、权限变化或原始筛选条件变化后，结果数量可能不同。看板中的固定项可以继续展示或刷新，但仍受原始引用和账户权限约束。

## 确认前的检查

创建相册、添加标签、批量喜欢等会改变整理关系的工具调用，必须先进入**需要确认**状态。确认窗口出现时，检查：

- 结果集数量与资源库范围；
- 是添加、移除还是覆盖；
- 是否会改变已有相册成员关系；
- 当前账户是否确实应当执行该操作。

取消、停止生成或关闭页面不会提交被中断的修改。不要把模型回复中的自然语言当作成功凭证，最终以页面结果和资源库实际状态为准。

## LLM 配置与数据边界

Lumilio Agent 使用 **设置 → AI** 中配置的 LLM 提供方、模型、Base URL 和 API Key。Lumen AI 节点与 Lumilio Agent 的 LLM 提供方是两条不同的数据路径：前者处理媒体派生数据，后者接收问题、引用上下文和工具结果。

启用远程 LLM 前，请确认隐私政策、费用、数据保留和 API Key 保存位置。模型上下文中不应出现不必要的账户、网络或资源库敏感信息。
