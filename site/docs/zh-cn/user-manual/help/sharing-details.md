# 分享链接进阶

日常创建和撤销请看[创建与管理分享链接](../features/sharing)。

## 创建时解析为快照

分享服务会在创建请求中把 `asset_snapshot`、相册、人物、工具结果或事件解析成一组媒体 ID，并把这组 ID 固定保存。之后源相册新增成员、人物聚类改变或筛选条件变化，都不会自动修改旧链接。想更新内容，需要撤销旧链接并创建新链接。

服务端单个快照最多 5000 项。事件分享也使用同一上限；超过上限时事件详情会拒绝分享，而不是静默截断。空集合也不会创建一个“看起来有效但没有内容”的链接。

## 令牌只在创建时出现

链接令牌由随机值生成，数据库只保存带作用域的哈希。管理页无法从哈希恢复原始 URL，因此创建成功后必须立即复制。公开请求会把未知、已过期和已撤销令牌统一视为“链接不可用”，避免通过错误差异探测链接状态。

公开媒体接口还会检查具体媒体是否属于快照，不能仅凭一个有效令牌访问其他资源库项目。公开返回的数据不会包含所有者、存储路径或内部文件名。

## 有效期和生命周期

- 创建请求未提供有效天数时，服务端默认 30 天；
- 服务端会把有效期限制在最多 365 天，界面当前提供 7、30、90 天；
- **延期**以“当前时间和原到期时间中较晚者”为基准再增加 30 天；
- **撤销**立即阻止公开访问；
- **删除记录**只允许已过期或已撤销的链接，避免误删仍在使用的公开凭证。

延期不会重新解析来源，也不会让已下载的文件消失。撤销和删除只影响链接记录，不影响快照中的原始媒体。

## 下载策略

“允许下载”控制公开页面是否显示打包下载；“包含原始文件”控制查看器是否提供单项原始文件。后者只有在前者打开时才会生效。即使关闭原始文件下载，公开页面仍可能允许查看缩略图、播放 Web 视频或音频；这不是 DRM。

任何能够打开有效 URL 的人都可以按页面提供的权限读取内容。若怀疑泄露，立即撤销，再用更小的快照和更短的有效期创建新链接。
