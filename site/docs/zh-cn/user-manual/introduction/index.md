# 认识 Lumilio Photos

Lumilio Photos 是一套在你自己的设备上管理图片、视频和音频的工具。它把浏览、整理、编辑和可选的本地 AI 放在同一个资源库中，同时尽量保留原始媒体与清晰的存储边界。

如果你只想在一台 Mac 或 Windows 电脑上使用，从 **Desktop** 开始最省心；如果你希望家中多台设备通过浏览器访问，并且熟悉 Linux 与 Docker，再选择 **Server**。

## 应用里有什么

- **首页**：回到最近内容，并从统一搜索框开始查找。
- **资源库**：浏览全部媒体，筛选、排序、选择并批量处理。
- **合集**：进入相册、事件、地图、人物、文件夹、标签与实用工具。
- **工作室**：对选中的图像进行非破坏性编辑并导出新文件。
- **管理**：上传、扫描和查看资源库接入状态。
- **设置**：管理账户、安全、用户、外观以及可用的服务连接。
- **状态**：管理员查看队列、存储和 ML 能力是否正常。

::: warning 仍是测试版
重要媒体应始终保留独立备份。不要把缩略图、索引或数据库当作原始媒体的替代品。
:::
