# 认识流明集（Lumilio Photos）

流明集是跑在你自己设备上的照片与视频管理工具：导入、浏览、搜索、相册、编辑、分享都在本地资源库中完成。**原件始终是普通文件，永远不会被应用覆盖**；缩略图、索引和识别结果只是为了更快查找，可以随时重建。

## 第一次使用，按这个顺序

1. [安装](./installation)：Mac 或 Windows 用桌面版，Linux 服务器/NAS 用 Docker。
2. [完成首次设置](./first-use)：创建管理员、建议开启两步验证、创建主资源库。
3. [把媒体加入资源库](../features/manage)：上传、扫描或云导入。
4. [创建并下载第一份数据库备份](./integrity)：几分钟的事，以后省心。

## 应用里有什么

| 入口 | 做什么 |
| --- | --- |
| 首页 | 最近内容、统计、地图概览 |
| 资源库 | 浏览全部媒体，搜索、筛选、批量操作 |
| 合集 | 相册、人物、地点、事件、标签、回收站等 |
| 工作室 | 非破坏性编辑并导出新文件 |
| 管理 | 上传、扫描、创建资源库 |
| 设置 | 账户、安全、AI、用户、偏好 |
| 状态 | 管理员查看后台任务和 ML 能力 |

## 可选能力

- **Lumen Intelligence**：本地语义搜索、人物识别、OCR、物种识别。不开也能正常用。
- **Lumilio Agent**：对话式整理助手。未配置时不影响任何基础功能。

::: warning 测试版
重要媒体请保留独立备份。本应用处于测试阶段，不要作为重要媒体的唯一副本。
:::
