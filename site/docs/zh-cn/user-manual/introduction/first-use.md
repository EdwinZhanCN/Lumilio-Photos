# 完成首次设置

安装完成后，首次设置要做三件事：**创建管理员 → 设置登录保护 → 创建主资源库**。桌面版从控制面板进入，Docker 版直接打开 Server 地址。

## 开始前

- 桌面版：确认控制面板中 Server 状态为「运行中」，浏览器已打开 `http://localhost:6680`。
- Docker：确认 `docker compose ps` 中 `lumilio` 健康，浏览器打开 `http://<主机IP>:6680`。

看到「首次运行设置」欢迎页后即可开始。

## 第一步：创建管理员

1. 选择界面语言与地区（仅影响当前浏览器）。
2. 填写用户名（3–32 字符，字母开头）和密码（10–72 字符，含大写、小写和数字）。
3. 点击**创建管理员并继续**。

**成功标志**：自动登录并进入安全设置。

## 第二步：设置登录保护（推荐）

向导依次询问 TOTP 验证器、通行密钥和恢复代码。

- **推荐启用 TOTP**：用验证器应用（如 Apple 密码、Google Authenticator、Microsoft Authenticator）扫描二维码并输入 6 位验证码。
- **通行密钥**：可选。启用 TOTP 后可用指纹/面容/安全密钥登记；只支持 localhost 或 HTTPS 地址。
- **恢复代码**：启用 TOTP 后显示的一次性代码，**务必保存到与运行设备分离的安全位置**。

可以暂时跳过，但管理员掌控整个 Server，跳过意味着账户只有密码保护。

## 第三步：创建主资源库

1. 填写**名称**（只用于界面显示，目录固定为 `primary`）。
2. **存储策略**：决定上传文件在 `inbox/` 中的排列方式，保留默认 `date`（按年/月归档）即可。
3. **同名冲突处理**：保留默认 `rename`（同名时安全重命名，不覆盖原件）。

**成功标志**：进入 Web 主界面。

## 验证首次设置

1. 打开**管理**，确认主资源库可用；
2. 加入几张照片，等待处理完成；
3. 打开**资源库**确认能查看和播放；
4. 到[备份与数据完整性](./integrity)创建第一份数据库备份。

## 失败时怎么办

- Desktop：查看控制面板中的 Server 状态和错误日志。
- Docker：`docker compose logs lumilio` 查看日志。
- 不要手动创建或删除 `primary` 目录；确认问题属于账户未创建、主资源库缺失还是存储路径不可写。
