# 理解资源库与原始文件

流明集把**存储位置**和**资源库**分成两层：

- **存储位置**：被授权使用的父目录（用 `.lumilioroot` 标记）。一个位置可包含多个资源库。
- **资源库**：独立的媒体集合（用 `.lumiliorepo` 标记），原始媒体文件就放在里面。

```text
存储位置/
├─ .lumilioroot
├─ primary/          ← 首次设置创建的主资源库
│  ├─ .lumiliorepo
│  ├─ inbox/         ← 上传和云导入的文件归档到这里
│  └─ .lumilio/      ← 缩略图、暂存、日志等，勿手动操作
└─ 家庭媒体/
   ├─ .lumiliorepo
   └─ inbox/
```

`inbox/` 外的目录是**自由区**：可以像普通文件夹一样整理文件，改动后执行**重新扫描**同步数据库。

::: danger 不要手动操作
不要手动改 `.lumilioroot`、`.lumiliorepo` 或 `inbox/`；不要重命名资源库目录。手动改动会导致数据库与文件不一致。
:::

## 同名冲突：原件永远不会被覆盖

上传或云导入遇到目标路径已有同名文件时，按创建资源库时选择的策略处理：

| 策略 | 行为 |
| --- | --- |
| **rename**（默认） | 安全重命名：追加 `(1)`、`(2)`，超 999 个回退时间戳 |
| **uuid** | 追加 8 位短 UUID，如 `photo_abc12345.jpg` |

三种结果：

- **同名同内容**：识别为重复项，不会写入第二份；
- **同名不同内容**：新文件重命名后写入，**已有文件保持不变**；
- **不同名同内容**：仍是重复项，按内容指纹判断，与文件名无关。

## 创建或连接资源库

**Desktop**：先在控制面板添加存储位置（父目录，如外接硬盘的 `Lumilio/`），再到浏览器**管理**页创建资源库。已有 `.lumiliorepo` 的目录用**连接已有资源库**流程，不要把非空目录当新资源库创建。

**Server**：把磁盘挂载为 `/data/storage/<资源库名称>` 下的子目录（**先挂载，再在 Web 创建资源库**，目录名必须与输入的名称完全一致），然后到**管理**页创建。

## 备份提醒

资源库目录只包含媒体；相册、账户、凭据存在应用状态目录的 SQLite 中，数据库备份也在资源库之外。完整备份见[备份与数据完整性](./integrity)。
