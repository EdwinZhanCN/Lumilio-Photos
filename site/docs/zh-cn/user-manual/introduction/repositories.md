# 理解资源库与原始文件

Lumilio 把**存储位置**和**资源库**分成两层：

- **存储位置**是被授权使用的父目录，用 `.lumilioroot` 标记身份。一个存储位置可以包含多个资源库。
- **资源库**是独立的媒体集合，用 `.lumiliorepo` 标记身份并记录存储策略。原始媒体文件就放在资源库内。

::: warning 隐藏文件与目录
`.lumilioroot`、`.lumiliorepo` 以及 `.lumilio/` 是隐藏文件与目录，默认情况下不可见。可以在 Windows、macOS 或 Linux 的文件管理器中开启显示隐藏文件来查看。
:::

资源库内的目录分为两类：

- **`inbox/`**：上传和云导入的文件由 Lumilio 自动归档到这里，归档路径由存储策略决定。

::: danger 不要手动操作 inbox
`inbox/` 中的文件由 Lumilio 的暂存和提交管道管理。不要在文件管理器中向 `inbox/` 添加、移动、重命名或删除文件——这会导致数据库记录与实际文件不一致。
:::

- **自由区**：`inbox/` 和 `.lumilio/` 以外的目录。你可以像使用普通文件夹一样在这里组织媒体文件，扫描会原地登记它们。

在自由区中添加、移动或删除文件后，执行**重新扫描**让 Lumilio 同步数据库记录。例如，把一批媒体从 `旅行/` 移到 `2024旅行/` 后，重新扫描会更新对应的路径。

存储策略的区别、`.lumilio/` 的完整结构和回收站等细节，请参阅[存储细节](../help/storage-details)。

::: info 数据库不在这棵树里
相册、人物、账户和任务等数据保存在应用状态目录的 SQLite 数据库中。密钥、云会话和数据库备份也在资源库之外。因此备份资源库目录并不等于完成了整套备份。参见[备份与数据完整性](./integrity)。
:::

## Desktop 与 Server 的存储差异

两种部署方式打开的是同一套界面，但存储管理能力不同。

### Desktop

默认存储位置在应用数据目录下的 `storage/`，首次设置时在此创建主资源库。外接硬盘或网络卷需要先在**控制面板**中通过系统目录选择器添加为存储位置，然后才能在该位置上创建或连接资源库。添加存储位置是操作系统级别的授权，不经浏览器。

### Server / Docker

存储路径在 TOML 配置中声明，部署时确定。运行时**无法添加**外部存储位置——Server 没有 Desktop 的目录选择器。媒体目录和应用状态目录是两个独立的挂载，必须分开管理。Docker 部署使用 host network，不转换端口。

## 三种容易混淆的操作

| 操作 | 在哪里执行 | 选择什么目录 | 会创建资源库吗 |
| --- | --- | --- | --- |
| **添加存储位置** | Desktop 控制面板 | 一个上级目录，例如外置硬盘中的 `Lumilio/` | 否，只登记 `.lumilioroot` |
| **创建资源库** | 浏览器中 | 从已登记且在线的存储位置中选择 | 是，创建 `.lumiliorepo` 和目录结构 |
| **连接已有资源库** | Desktop 控制面板 | 已经包含 `.lumiliorepo` 的资源库目录 | 否，只登记已有资源库 |

::: tip 要在外接硬盘上创建新资源库
先在控制面板把硬盘上的**父目录**添加为存储位置，再回到浏览器创建资源库并选择这个位置。不要把空目录交给"连接已有资源库"——它只接受已经包含 `.lumiliorepo` 的目录。
:::

主资源库是例外：它在首次设置时创建，只能位于默认存储位置，不能删除。完成首次设置后，普通资源库可以创建在任意已登记且在线的存储位置中。

## 注意事项

- **不要手动修改** `.lumilioroot` 或 `.lumiliorepo` 标记文件。移动资源库时使用控制面板的连接流程。
- **不要手动操作 `inbox/`**：`inbox/` 由 Lumilio 管道管理，手动添加、移动、重命名或删除会导致数据库与文件不一致。
- **自由区改动后需重新扫描**：在 `inbox/` 和 `.lumilio/` 以外添加、移动或删除文件后，执行重新扫描同步数据库。
- **移除外接硬盘前**，先确认没有正在运行的后台任务。
- **备份**要同时覆盖媒体目录和数据库。应用内的数据库备份只包含相册、人物等目录数据，不含媒体原件。
- **存储策略**只影响上传和云导入的归档路径，不影响扫描。
- **运行 Lumilio 的系统账户**必须能读取资源库；上传和内部管理还需要写入权限。

如果磁盘挂载点或 Windows 盘符变化，重新添加同一存储位置并选择"重新连接到此处"。只有确认是同一块已移动的磁盘时才这样做。
