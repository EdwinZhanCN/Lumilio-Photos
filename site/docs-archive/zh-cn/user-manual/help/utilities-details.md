# 工具进阶

基础操作见[重复项、喜欢与回收站](../features/utilities)。

## 重复检测不是导入去重

上传和云导入会使用内容指纹避免把同一份内容再次接入；**重复项扫描**则是对已经登记的资源库运行另一套完全重复和视觉相似分析。扫描结果按资源库隔离，管理员在管理页的资源库卡片中发起扫描。

候选组的“完全重复”与“视觉相似”方法可能混合出现。相似组不保证字节一致，也不保证拍摄时间、编辑指令或元数据相同，不能直接当作自动删除清单。

## 合并是可回收的软删除

合并时服务端保留你选中的项目，并把可合并元数据写入保留项；其他成员被标记为已删除并进入回收站。资源库文件不会因为合并按钮而立即从磁盘消失，因此可以先在回收站复核。当前 Web 工具页没有“永久删除”操作；实际清理策略仍受服务器和备份流程约束。

标记**不是重复**只改变候选组状态，不会移动或修改媒体。状态筛选让管理员可以回看已合并和已忽略的组。

## 回收站与合集的区别

回收站筛选的是媒体的 `is_deleted` 状态，只提供恢复操作；相册移除、标签移除和喜欢取消都不是删除。删除相册容器也不会把相册成员送入回收站。恢复后，媒体回到普通资源库浏览，但缩略图或其他派生任务可能需要重新排队。

## AI 分类器是来源为 zeroshot 的标签

文档、收据和插画入口实际上是按 `zeroshot` 来源标签筛选的工具视图。它们不创建新的相册，也不改变文件目录；关闭对应 ML 能力后，已有标签可能仍可查看，但不会继续生成新结果。需要人工确认的内容应使用手动标签或相册保存。

工具页中的所有入口都受当前账户权限和资源库范围约束。管理员查看重复摘要或发起扫描时，应明确选择目标资源库，避免把“全部资源库”的浏览范围误认为扫描范围。
