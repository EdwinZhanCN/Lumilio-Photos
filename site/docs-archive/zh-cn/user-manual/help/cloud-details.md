# 云导入进阶

基础流程见[外部来源与云连接](../features/cloud-import)。

## 提供商和凭据

Web 页面不会写死所有 provider，而是从 Server 获取提供商描述、字段和挑战字段。当前代码提供 iCloud Photos 适配器；未来 provider 可以复用同一套凭据和导入界面。提供商状态为“已停用”时，界面会保留记录但禁止新建连接。

创建凭据时，Server 只把认证结果和会话状态保存到应用状态目录；Web 不会再次显示完整密码。需要短信或二次验证时，凭据先处于 `pending_challenge`，验证成功才变为 `connected`。

## 增量导入

导入器按 provider 的远程键和 ETag 保存游标：

- 首次运行从头列出远程项目；
- 后续运行优先读取自上次成功位置之后的变化；
- 已下载且 ETag 未变的项目会被跳过；
- 下载到暂存目录后，继续走普通资源库的媒体校验、归档和派生任务。

一次运行的 `queued`、`running`、`completed`、`failed` 或 `interrupted` 状态属于该资源库与凭据绑定。凭据会话过期时，先在设置中重新连接，再重试导入。

## 为什么远程删除不会删除本地媒体

云适配器会记录远程删除标记，但当前导入模式明确忽略这些 tombstone，不对本地媒体执行删除。这样可以避免云端误操作或短暂权限问题把本地资源库变成镜像丢失。若确实要删除本地项目，请在 Lumilio 中使用回收站，并按自己的备份策略处理。

云导入的缓存、游标和凭据目录不属于原始媒体备份；迁移 Server 时必须同时迁移应用状态和完整资源库。
