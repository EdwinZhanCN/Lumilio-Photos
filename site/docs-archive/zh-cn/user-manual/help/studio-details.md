# 工作室进阶

基础操作见[在工作室编辑静态媒体](../features/studio)。

## sidecar 保存什么

工作室保存的是版本化的 `LumilioSidecarV1`：它包含源媒体标识和文件快照信息、调整参数、裁剪/旋转/翻转、画布、文字图层和更新时间。sidecar 不包含渲染后的像素，因此：

- 原始文件仍是唯一的源；
- 调整可以在未来重新渲染；
- 清除浏览器的最近编辑列表不会删除 sidecar；
- 删除或移动原始媒体后，sidecar 不能独立恢复一个可用文件。

同一项媒体在不同设备打开时，只要登录同一 Server，就能读取已保存的 sidecar；未保存的浏览器内状态不会同步。

## 预览和导出为什么可能不同

预览使用浏览器 Worker 和 WebGL/WebGPU 在较小画布上渲染，导出才使用更大的工作源并编码成文件。设备 GPU 限制、长边上限和裁剪后的几何可能让导出自动缩小；界面提示的实际尺寸才是最终结果。

深度估计是可选效果：它先对调整后的静态媒体生成深度场，再让文字图层按深度产生遮挡。没有 WebGPU、模型或足够内存时，深度效果会失败或不可用，不影响普通裁剪、调整和导出。

## 格式与元数据

| 格式 | 适合 | 注意 |
| --- | --- | --- |
| JPEG | 通用分享、较小体积 | 有损编码，质量越高体积通常越大 |
| PNG | 无损、透明区域 | 体积可能较大；不会保证复制 EXIF |
| WebP | 现代浏览器和网页 | 接收方需支持 WebP |

非 PNG 导出会尽力从原始文件复制兼容的 EXIF，并根据导出后的方向更新元数据；如果原始文件不可读或工具不支持某字段，导出仍可能成功但元数据不完整。导出文件是下载结果，不会自动重新导入资源库。

::: warning 不要把导出文件当作“保存”
导出得到的是一个新文件，保存得到的是可重放的编辑指令。若想让新文件成为资源库中的另一项媒体，请按普通上传流程导入，并确认重复项和文件布局策略。
:::
