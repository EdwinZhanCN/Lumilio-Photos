# 使用指南

<DocPath :items="['侧边栏', '使用指南']" />

建议按下面的顺序熟悉 Lumilio Photos：

1. **导入**：先读[把媒体加入资源库](./manage)，理解上传、扫描、云导入和后台处理的区别；
2. **浏览**：再读[浏览、筛选与批量操作](./assets)，学会先选资源库范围，再搜索、筛选和批量处理；
3. **整理**：使用[相册与合集](./collections)以及[人物、地点与事件](./people)建立手动和自动视图；
4. **清理**：在[重复项、喜欢与回收站](./utilities)中审核候选，确认后再合并或恢复；
5. **输出**：需要新文件时使用[工作室](./studio)，需要他人查看时使用[分享链接](./sharing)；
6. **增强**：确认基础流程稳定后，再按需启用 [Lumen Intelligence](./lumen-intelligence) 或 [Lumilio Agent](./agent)；
7. **维护**：管理员使用[账户、用户与偏好](./settings)和[检查任务与服务状态](./monitor)处理安全、备份和后台任务。

“合集”是组织和浏览入口，不是新的存储位置；Lumen Intelligence 和 Lumilio Agent 也是可选增强，不会替代原始媒体备份。遇到路径、挂载、扫描排除或队列诊断问题，再打开“更多帮助与支持”中的进阶页面。
