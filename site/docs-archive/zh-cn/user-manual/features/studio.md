# 在工作室编辑静态媒体

<DocPath :items="['侧边栏', '工作室']" />

工作室当前选择**图像类媒体**作为编辑源，不处理视频和音频。它以原始媒体为输入，在浏览器中实时预览调整结果；保存时写入编辑指令，导出时才生成一个新的文件。资源库中的原始媒体不会被覆盖。

## 从工作室开始

1. 打开**工作室**，点击**打开编辑器**，或从最近编辑中点击**继续**；
2. 在选择器中选择一项图像类媒体。也可以从查看器或其他入口通过 `assetId` 直接打开编辑器；
3. 使用右侧面板的**调整、裁剪、边框、文字**标签编辑；
4. 需要保留当前编辑指令时点击顶部**保存**；
5. 需要得到可发送或打印的文件时点击**导出**，选择格式、质量和尺寸后下载。

最近编辑列表只保留媒体标识、名称、尺寸和时间，保存在当前浏览器中。清空最近编辑不会删除已经保存的编辑指令，也不会删除原始媒体。

## 四类编辑工具

- **调整**：曝光、对比度、高光、阴影、白色、黑色、色温、色调、鲜艳度、饱和度、清晰度、锐度和降噪；
- **裁剪**：自由裁剪或使用宽高比预设，并可旋转、水平翻转、垂直翻转；
- **边框**：纯色、渐变或毛玻璃背景、留白、圆角、暗角和信息条预设。带相机参数的预设需要源媒体存在可用 EXIF；
- **文字**：添加多个文字图层，设置字体、字号、颜色、透明度、描边、阴影和位置。可选的场景深度估计让文字图层产生前后遮挡效果，但需要浏览器支持 WebGPU 和相应模型。

编辑器顶部的**按住查看原图**只改变预览，不会清除调整。**撤销**和**全部重置**也只作用于当前编辑会话，重置后仍需保存才会更新已保存的编辑指令。

## 保存与导出不是一回事

**保存**会向媒体的 sidecar 写入版本化编辑指令（调整、构图和文字图层），不会把渲染后的像素替换回资源库。下次打开同一项媒体时，编辑器会重新读取这些指令。

**导出**会在浏览器中渲染当前预览并下载新文件，文件名通常会追加 `-lumilio`。可选格式为 JPEG、PNG 和 WebP；如果设备或 GPU 无法处理原始尺寸，导出会自动缩小并提示实际尺寸。JPEG/WebP 尽量保留兼容的 EXIF，PNG 不保证复制 EXIF。

::: warning 离开前先处理未保存状态
预览中的改动和已经保存的 sidecar 是两件事。切换媒体、刷新页面或关闭浏览器前，先点击**保存**或**导出**；仅看到预览变化并不表示结果已经写入资源库。
:::

工作室的 sidecar 结构、渲染边界、EXIF 处理和深度模型限制见[工作室进阶](../help/studio-details)。
