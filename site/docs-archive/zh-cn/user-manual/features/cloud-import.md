# 外部来源与云连接

云连接分成两步：**设置页保存并验证凭据**，**管理页把凭据绑定到资源库并启动导入**。只完成第一步不会产生任何媒体。

## 第一步：连接云凭据

1. 打开[设置](./settings)的**云导入**标签页，点击**添加凭证**；
2. 选择界面列出的提供商，填写账号、密码和提供商要求的选项；
3. 如果出现验证码表单，输入提供商发送的验证码并点击**验证**；
4. 确认凭据状态显示为**已连接**。

当前版本的提供商和字段由 Server 动态返回；如果某个提供商没有出现在列表中，说明当前部署没有启用它。凭据、会话和导入进度属于当前账户，管理员不能代替其他用户使用其云凭据。

## 第二步：绑定资源库并导入

### 创建资源库时导入

在**管理 → 添加资源库**中：

1. 输入合法的资源库名称并选择存储位置；
2. 将来源切换为**云端**；
3. 选择状态为**已连接**的云凭据；
4. 选择文件布局和同名冲突处理策略；
5. 创建资源库。

资源库创建成功后会自动排队一次导入。资源库已经创建但首次导入失败时，卡片会显示“已创建但导入未启动”的提示；先修复凭据或网络，再从卡片菜单重新启动。

### 对已有资源库再次导入

打开资源库卡片的 **⋯** 菜单，选择**从云端导入**。只有已绑定云凭据的资源库才会显示此操作。任务处于**排队**或**运行中**时，按钮会暂时禁用；卡片会显示最近一次运行的状态、导入数量、跳过数量和失败数量。

云端文件会先作为导入源下载到资源库的 `inbox/`，再按创建资源库时选择的策略归档。它与浏览器上传使用同一套媒体校验、重复判断和后台派生处理。

::: warning 云导入是“导入”，不是双向同步
远程删除不会自动删除本地已经导入的媒体；本地对媒体的修改也不会回写云端。云服务的会话过期、二次验证、网络限流和服务端行为都可能让一次运行失败，失败后请查看资源库卡片和[状态页](./monitor)。
:::

## 断开、重新连接与移除

在**设置 → 云导入**中：

- **断开**会停止当前会话，进行中的导入可能中止；
- **重新连接**会尝试使用已保存凭据建立新会话；
- **移除**会删除本地凭据和会话目录，但保留已经导入的媒体、资源库和数据库记录。

如果移除凭据后仍要导入，必须重新添加并验证凭据，然后在资源库卡片中重新启动。不要删除资源库的 `inbox/` 或 `.lumilio/` 来“清理云导入”；这些目录由资源库管道管理。

云 provider 字段、会话挑战和导入运行状态的服务端边界见[云导入进阶](../help/cloud-details)。
