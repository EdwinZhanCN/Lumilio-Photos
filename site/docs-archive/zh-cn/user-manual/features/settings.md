# 账户、用户与偏好

<DocPath :items="['侧边栏', '设置']" />

**设置**按标签页组织不同类型的配置。账户和外观是每个用户都可能使用的内容；**AI**和**用户管理**只对管理员显示。保存前先看清当前标签页，因为有些选项只影响当前浏览器，有些会改变整个 Server。

## 账户：先保护好登录方式

在**账户**标签页可以：

- 修改显示名称和头像。头像从已有媒体中选择，不会因此复制或删除原始文件；
- 修改密码。密码修改成功后当前会话会退出，需要重新登录；
- 启用或停用身份验证器应用（TOTP），查看剩余恢复码并重新生成恢复码；
- 注册和移除通行密钥。当前实现要求先启用 TOTP，且浏览器必须支持通行密钥并处于安全上下文。

建议在更换 TOTP 或通行密钥前，先确认另一种登录方式和恢复码仍可用。恢复码重新生成后，旧恢复码立即失效。

## 外观：只改变当前浏览器的显示

**外观**标签页提供三组偏好：

1. **语言和地区**：选择界面语言，以及日期、数字等区域格式；
2. **主题配对**：可以跟随操作系统，也可以分别选择亮色和暗色主题；
3. **资源页面**：选择**舒展**或**紧凑**布局；紧凑布局还可以调整每行的列数。

这些偏好保存在当前浏览器的本地设置中。换浏览器、清理站点数据或使用另一台设备后，需要重新选择；它们不会改变媒体、资源库或其他用户的设置。

## 云导入：只管理凭据和会话

在**云导入**标签页点击**添加凭证**，选择界面列出的提供商，填写账号信息。部分提供商会要求输入短信或其他验证码；验证完成后，凭据才会变成**已连接**。

- **断开**：保留凭据记录但停止当前会话，之后可以重新连接；
- **重新连接**：重新建立已保存凭据的会话；
- **移除**：删除本地凭据和会话数据，已经导入资源库的媒体不会被删除。

云凭据本身不会自动导入任何内容。创建资源库时选择云来源，或在已绑定云凭据的资源库卡片中点击**从云端导入**，才会启动导入。详情见[外部来源与云连接](./cloud-import)。

::: warning 凭据与授权
云账号密码只应在受信任的 Lumilio 页面中输入。断开或移除本地凭据不等于撤销云服务提供商侧的其他授权；如需彻底撤销，请同时检查提供商的账户安全页面。
:::

## 服务器：检查运行信息与数据库备份

**服务器**标签页包含：

- **健康检查间隔**：当前浏览器多久检查一次 Server 在线状态，范围为 1–50 秒；
- **数据库备份**：启用自动备份、选择间隔、设置保留数量，也可以立即创建、下载、恢复或删除一个备份；
- **运行时配置**：只读显示当前 TOML 清单解析后的结果，例如监听地址、TLS、存储根目录、扫描和 Lumen Intelligence 状态。

应用内备份只包含 SQLite 中的目录数据（相册、人物、编辑记录等），不包含原始媒体文件。恢复是异步操作：点击**恢复**只是提交请求（服务器返回 `202 Accepted` 和 operation ID），不代表恢复完成；页面短暂断线属于预期行为，可以凭 operation ID 回到设置页继续观察。恢复流程会经过暂存、重启、安装、验证等阶段，验证失败时旧数据库会自动恢复。详见[备份与数据完整性](../introduction/integrity)。恢复前应确认备份时间和来源正确，并确保原始媒体与应用数据另有独立备份。

运行时配置不能在 Web 页面直接编辑。Server 部署者需要修改完整 TOML 清单并重启服务；Desktop 的路径、监听、证书和日志由 Desktop 控制面板管理。

## AI：管理员配置可选能力

管理员才会看到**AI**标签页，它管理两类独立的能力：**Lumilio Agent**（对话式整理助手）和 **Lumen Intelligence**（媒体理解任务）。两部分的开关都要求**显式选择**，不存在静默回退到某个默认服务的路径。

### 选择 LLM 提供方（Lumilio Agent）

- 提供方必须**显式选择**：没有选择、选择未知或为空时，Agent 处于未配置状态，不会回退到任何默认提供方；
- 选择提供方后填写模型名称。**DeepSeek、Ollama 等 OpenAI 兼容提供方必须显式填写 Base URL**，避免连接错误默认端点；**远端提供方需要 API Key**；
- **验证连接**验证的是当前未保存的草稿：验证通过前不会保存，验证失败更不会保存任何内容；
- **切换提供方需要重新提供 secret**：已保存的 API Key 只属于原提供方，不会自动带到新提供方；
- “**启用 Lumilio Agent**”和“**验证提供方**”是两个不同的动作：启用开关只改变 Agent 的可用状态，验证按钮只检查连接；服务端在启用前还会再次执行结构完整性检查。

### 媒体理解任务（Lumen Intelligence）

- **ML** 区域分别启用图像语义分析、视频语义、BioCLIP物种识别、OCR文字识别和人物识别任务。视频语义依赖图像语义分析，关闭父项时会一并关闭。

### 关闭某项后的行为

这些开关不会删除已经存在的媒体或目录数据。关闭某项后，依赖它的新任务不会继续排队，已有结果仍可能保留；重新启用后，管理员可在[状态页](./monitor)按需重建索引。

Lumen Intelligence 节点本身的安装与再配置在 Desktop 控制面板、`lumen-cli configure` 或 Docker 中完成，见 [Lumen Intelligence](./lumen-intelligence)。

## 用户管理：修改已有账户的访问范围

管理员在**用户管理**标签页可以选择已有账户并修改：

- 用户名、显示名称和头像；
- **用户**或**管理员**角色；
- 账户是否处于活跃状态。

界面会列出账户的资源和相册数量，便于确认选中的对象。这里没有“删除用户”操作；停用账户会阻止其登录，但不会自动删除其拥有的媒体。

如果其他用户失去了所有登录因子，管理员可以使用**重置访问权限**生成一次性临时密码。该操作会清除对方的 TOTP、恢复码和通行密钥；请通过安全渠道一次性传递临时密码，并提醒对方登录后立即设置新的密码和验证方式。管理员不能用这个按钮重置自己的账户。

## 关于

**关于**标签页提供使用条款、开源许可证、第三方软件声明和项目仓库链接。遇到功能或版本问题时，提交反馈前可先记录这里显示的版本与运行信息。

::: info Desktop 控制面板不在 Web 设置中
Desktop 的存储位置授权、Server 启停、Lumen Intelligence 安装和缓存、证书、日志以及需要重启的运行配置，都在 **Desktop 控制面板**。Web 的**设置**页只管理上面列出的账户、偏好和 Server API 配置；不要在两处重复设置同一项。
:::

涉及恢复码、通行密钥、备份替换和运行时清单的进阶边界，请阅读[设置与状态进阶](../help/maintenance-details)。
