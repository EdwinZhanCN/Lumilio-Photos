# 相册与合集

<DocPath :items="['侧边栏', '合集']" />

**合集**是同一批媒体的组织和浏览入口，不是新的存储位置。它不会复制或移动原始文件；同一项媒体可以同时出现在相册、文件夹、标签和自动整理视图中。

## 先按目标选择入口

| 你想做什么 | 使用哪个入口 | 它的特点 |
| --- | --- | --- |
| 手动整理一组媒体 | **相册** | 由你维护成员关系，可以添加、移除、重命名和分享 |
| 按现有目录寻找媒体 | **文件夹** | 直接反映资源库中的来源路径，不需要重新整理目录 |
| 给跨目录的媒体加一个主题 | **标签** | 可以区分手动标签和 AI 生成标签 |
| 查看识别出的人物或位置 | **人物**、**地点** | 来自人脸、GPS 和时间等信息，属于自动生成的视图 |
| 按时间和地点回顾一段内容 | **事件** | 自动聚合，也可以在详情页进行人工修正 |
| 查看喜欢、清理或打开分享链接 | **工具** | 包含喜欢、重复项、回收站、分享链接和智能分类 |

## 从合集首页开始

1. 在侧边栏打开**合集**。
2. 在标题栏的**图库范围**中选择**全部资源库**，或先选择一个具体资源库。范围会影响当前页面能够看到的媒体；切换范围不会改变文件位置或合集成员关系。
3. 首页用卡片预览各个入口。点击**查看全部**进入对应的完整列表；点击卡片可以直接打开某个相册、人物、文件夹或行程。

::: tip 如何判断一个视图是否会改变整理关系
只有相册、手动标签、喜欢状态以及事件详情中的人工修正会写入整理状态。文件夹、地点和人物是根据已登记的媒体信息生成的视图；扫描或后台分析完成后，它们可能出现新的结果。
:::

## 相册：手动组织媒体

### 创建相册

1. 打开**合集 → 相册**，点击**新建相册**。
2. 输入**相册名称**；描述可以留空。
3. 点击**选择封面**，从已有媒体中选一项作为封面。新建相册时必须先选封面。
4. 如需使用 BioCLIP物种识别，可以打开**生物图鉴**；普通相册不需要打开它。
5. 点击**创建相册**。

创建相册只建立一个容器，不会自动把整个资源库加入其中。回到资源库浏览页，进入选择模式，使用**添加到相册**；也可以在查看单项媒体时把它加入相册。

### 浏览和维护相册

打开相册后，可以：

- 在标题区域编辑名称、描述、封面和相册类型；
- 分享整个相册，或只分享选中的媒体；
- 进入选择模式，使用**从当前相册移除**批量解除成员关系。

::: warning 移除成员不等于删除媒体
从相册移除只改变“这个媒体属于哪个相册”。原始媒体仍在资源库中，也不会因此进入回收站。需要删除媒体时，应在资源库浏览页明确使用**移入回收站**。
:::

在相册列表进入选择模式，可以批量**删除相册**。删除的是相册容器及其成员关系，不会删除其中的原始媒体。相册可以跨资源库包含媒体；如果只想查看某个资源库中的成员，先在页面顶部选择对应范围，想查看完整成员时切换回**全部资源库**。

## 文件夹：按来源路径浏览

文件夹来自媒体在资源库中的相对路径。文件夹列表先按资源库分组，再显示每个目录的媒体数量、日期范围和封面。打开一个文件夹后，详情页会同时显示该目录及其子目录中的媒体。

文件夹不是需要单独维护的副本，也不提供“在合集内新建、重命名或移动文件夹”的操作。你在文件系统中移动媒体并完成扫描后，路径视图才会随扫描结果更新。想了解扫描范围和受保护目录，请阅读[导入与扫描进阶](../help/ingest-details)。

## 标签：跨目录分类

标签入口位于**合集 → 工具 → 标签**。标签页提供：

- 按名称搜索；
- **全部 / 手动 / AI**来源筛选；
- 点击标签卡片查看所有匹配媒体。

在资源库或单项查看器中添加的标签属于**手动**来源，可以继续编辑或移除。AI 标签由分类器维护，适合用来筛选和发现，不应当把它当作人工确认的结论。同一个标签名称在不同来源下是不同的分类，查看时请注意来源筛选。

## 人物、地点与事件

- **人物**按检测到的人脸聚合。人物列表可以在**显示中**和**全部**之间切换；隐藏人物只会从默认列表中隐藏，不会解除媒体与人脸的关联。详情页可以重命名、检查或分享。更多说明见[人物、地点与事件](./people)。
- **地点**只显示带有可用 GPS 坐标的媒体。地图上的点和行程是分析结果，没有位置元数据的媒体不会因为打开地图而出现。
- **事件**按时间和地点整理一段媒体。打开事件后可以重命名、设置封面、添加或移除媒体、合并或拆分事件，也可以隐藏或分享。事件的自动结果需要视为整理建议；修改后可能需要重新构建才能完全反映新的分组。

## 工具：整理、清理和分享

打开**合集 → 工具**可以使用：

- **喜欢**：集中查看已标记的媒体，并批量取消喜欢；
- **重复项**：检查完全重复或视觉相似的候选组，选择保留项后再合并；
- **回收站**：恢复或进一步处理已移入回收站的媒体；
- **标签**：搜索和按来源浏览标签；
- **分享链接**：集中检查、复制或撤销已创建的链接；
- **文档、收据、插画**：按可用的 AI 分类结果浏览媒体。

重复项、喜欢和回收站的处理边界见[重复项、喜欢与回收站](./utilities)，分享链接的安全检查见[创建与管理分享链接](./sharing)。

::: danger 不要把合集当作备份
相册、标签、人物、地点和事件都依赖数据库中的关系或派生索引。它们不会替代原始文件备份；删除相册也不会产生一份可恢复的媒体副本。涉及批量删除或合并前，请先确认选中的范围和“受影响资源”数量。
:::

遇到相册数量、资源库范围、标签来源或自动行程与网格结果不一致时，请阅读[相册与合集进阶](../help/collections-details)。
