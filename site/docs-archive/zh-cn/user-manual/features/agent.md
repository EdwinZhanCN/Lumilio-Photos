# Lumilio Agent

Lumilio Agent 是 Lumilio Photos 中的对话式整理助手：你可以用自然语言描述想做的事，由 Agent 在**当前账户和已授权资源库的范围内**调用整理工具。它不是聊天玩具，而是一个受控的媒体管理闭环：

```text
明确媒体范围 → 提问/选择模式 → 可观察的工具执行
→ 精确确认影响范围 → 权威 effect receipt → 查看结果
```

Agent 与 [Lumen Intelligence](./lumen-intelligence) 相互独立：Agent 需要配置 LLM 提供方（见文末[配置、提供方与隐私](#配置提供方与隐私)），Lumen Intelligence 负责图像语义分析、人物识别、OCR文字识别和 BioCLIP物种识别。**基础媒体库不依赖其中任何一个**：未配置 Agent 时，导入、浏览、相册和备份照常工作。

## 从哪里打开 Lumilio Agent

- 侧边栏中的 Agent 页面；
- 全局浮动入口；
- 媒体查看器中的提问入口。

不同入口都使用同一套账户权限和资源库范围。未登录、没有资源库访问权或 LLM 配置不可用时，Lumilio Agent 不会绕过这些限制读取媒体。

## 第一步：明确媒体范围

Agent 通常不会“凭空知道”你想处理哪些媒体。把范围说清楚，或直接从选中媒体开始：

- 直接说明范围：“**2024 年旅行相册里**的照片”“**海边**这个合集中的视频”；
- 在资源库中选中一批照片后提问，本次会话会记住这个选择；
- 引用（mention）人物、相册、合集、相机、镜头、事件或固定项。

**每条用户消息旁都会显示本次的 mode（模式）、selection/viewing scope（选择/查看范围）和 mentions（引用）**，用于确认 Agent 看到的是不是你想让它处理的媒体。**被丢弃的引用不会静默忽略**：如果某个提及无法解析或超出权限，会在消息旁明确标出，你可以修正后再继续。

结果集是当前查询和权限下的工作快照，不是永久不变的筛选器。新导入、删除、回收站恢复或权限变化，都可能使它与稍后打开的浏览页不同。

## 第二步：选择模式并观察工具执行

按任务类型选择模式，例如**整理**（建册、打标签、批量操作）或**分析**（统计、审阅）。工具调用是**可观察**的：界面会显示正在执行哪个工具、处理了多少媒体；你可以随时停止生成。

取消、停止生成或关闭对话不会自动提交被中断的修改。

## 第三步：精确确认影响范围

会改变整理关系的操作（创建相册、添加标签、批量喜欢等）会停在**需要确认**状态。确认前可以预览影响范围，至少检查：

- 目标资源库和当前账户；
- 结果集数量是否符合问题本意；
- 操作是添加还是移除、会影响哪些媒体；
- 是否会影响已有相册成员关系或回收站状态。

**点击确认只表示提交**，不代表操作已经生效。确认后界面会依次显示 `submitting → committed / rejected / failed / cancelled`；只有看到服务器返回的 **effect receipt（效果回执）**，才能认为操作已应用。

## 第四步：以 effect receipt 为准

- 回执由服务器在事务提交后签发，是操作成功的**权威凭证**；页面提示以回执为准，而不是模型回复里的自然语言；
- 每次运行结束后回执保留 30 天，可在按用户 + 对话 + 效果的记录中**对账**：谁、何时、对哪些媒体、执行了什么操作；
- 并发确认时，只有仍处于 pending、尚未绑定的效果才会被执行，避免同一批媒体被重复操作。

## 工作记忆与持久事实

会话中的工作记忆是**临时的**：关闭对话或开始新会话后，Agent 不会记得之前的讨论。真正持久的事实是：

- 你在看板（Board）中固定的内容；
- pin 住的引用与结果；
- 媒体本身的变更（相册成员、标签、喜欢状态）；
- 服务器签发的 effect receipt。

需要保留某个结果，就把它固定到看板或执行操作，而不是依赖对话记录。

## 状态：未配置、禁用与不可达

Agent 的可用状态有三种，含义不同：

- **未配置**：还没有选择 LLM 提供方和模型。Agent 入口会明确提示，不会假装可用；
- **禁用**：管理员关闭了“启用 Lumilio Agent”。入口可见但不可用；
- **不可达**：provider 已配置，但连接失败、密钥无效或服务端校验未通过。

这三种状态都会如实显示。基础媒体库不依赖 Lumilio Agent，任何状态下导入、浏览和整理照常工作。

## 配置、提供方与隐私

管理员在 **设置 → AI** 中配置（详见 [AI 设置](./settings#ai管理员配置可选能力)）：

- **显式选择 LLM 提供方**：不会静默回退到某个默认服务；未知或空值直接视为未配置；
- **验证连接**：验证的是当前未保存的草稿，验证失败不会保存；
- **切换提供方需要重新提供 secret**：已保存的密钥只属于原提供方；
- DeepSeek / Ollama 需要显式填写 Base URL；远端提供方需要 API Key。

**数据边界取决于提供方和部署方式**：

- **本地提供方**（如 Ollama）：问题和引用的媒体元数据留在你的设备上；
- **远端提供方**：Agent 的问题、引用的上下文和工具结果会发送给该服务，是否离开本机取决于对方的数据保留规则。

启用远程提供方前，请检查提供方的隐私政策、费用和数据保留规则。Lumilio 会把模型上下文中的账户、网络或资源库敏感信息控制在任务所需范围内。

Agent 引用、结果集快照、看板和确认边界见 [Lumilio Agent 进阶](../help/agent-details)。
