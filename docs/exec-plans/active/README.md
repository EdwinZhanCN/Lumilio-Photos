# Active Exec Plans

Only unfinished implementation plans live here — there is no completed
archive. Follow the
[lumilio-exec-plan](../../../../../.agents/skills/lumilio-exec-plan/SKILL.md)
skill for when a piece of work earns a plan, the plan skeleton, and
maintenance.

Completing a plan means: verify its validation boundaries pass, extract the
durable decisions (with alternatives) into `.agents/decisions/`, move any
surviving debt to [tech-debt-tracker.md](../tech-debt-tracker.md), update the
owning reference docs, then delete the plan file. Git history retains the
full record; implementation chronology is never kept here.
