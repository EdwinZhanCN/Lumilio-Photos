# Decision Records

Project-coupled decisions: why things in this codebase are the way they are,
and — mandatory — what each decision beat. Format, when to write one, and the
Obsidian boundary are owned by
[agent-harness.md](../../site/docs/internal/agent-harness.md#decision-records).

Files are `YYYY-MM-DD-topic.md` (date of the decision), flat, with
`Status: implemented` or `Status: rejected — <one line>` and a mandatory
`## Alternatives considered` section. Supersede with a new file and
cross-link; never rewrite a record into a different decision.
